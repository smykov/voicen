## Goal

The release-1 flow works end to end via an OpenAI-compatible API: on Windows the user configures the engine in the settings window, holds the hotkey in Notepad, speaks, and the text is pasted; failures are reported and retryable; every commit is built, installed and smoke-checked on the Windows CI runner.
