# Voicen — режим созвона, релиз 1: пакет для агента проекта

Составлено 21.10.2026 владельцем вне репозитория; копия — 21.10.2026. Это входные данные для агента репозитория `/projects/voicen`. По этому пакету агент делает требования в формате проекта, спецификации (Spec Kit) и проектирование. Сам пакет — не спецификация: это ТЗ владельца с решениями и вариантами.

**Статус:** v4 от 21.10.2026.
- v2 — ответы владельца на ВВ-1…ВВ-6 (все предложения приняты).

- v4 — ответы владельца на П-1…П-6, порядок поставки 1a–1d (`tz.md`, разд. 11–12).

**Готов к передаче агенту.** Условие (П-2): работа над режимом созвона начинается после публикации релиза 1 диктовки (T-026, T-028).

## Как передавать агенту

1. ~~Владелец отвечает на ВВ-1…ВВ-6~~ — сделано 21.10.2026.
2. Пакет лежит в `docs/briefs/call-mode-r1/` (скопирован 21.10.2026). Агенту даётся задание:
   - переложить в `docs/requirements.md` на английском как новый релиз (новые FR и NFR, номера продолжают существующие);
   - перенести решения в `docs/decisions.md`;
   - запустить `/teamwright:requirements` (прожарка), затем спецификации и проектирование **по инкрементам 1a → 1d** (`tz.md`, разд. 11): сначала спека и задачи 1a, следующие — по мере готовности.
3. Агент не меняет решения со статусом «принято владельцем». Расхождения с кодом выносит в `docs/open-questions.md`.

Нумерация ВФ, ВН, ADR и ВВ — внутренняя для пакета. Агент сам назначает номера FR и NFR в репозитории.
