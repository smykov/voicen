# ADR-004. Движок диаризации и итогового распознавания

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **принято владельцем** 21.10.2026 (ВВ-2)

## Контекст
Принцип Voicen — без своего облака: ключи пользователя или локальные движки. Варианты:
- **Локально:** sherpa-onnx — сегментация pyannote-3.0 + эмбеддинги голоса (3D-Speaker, WeSpeaker, NeMo) + кластеризация. Есть официальный крейт `sherpa-onnx` с примером офлайн-диаризации. Обёртка `sherpa-rs`, по словам конкурента, заархивирована ⚠. Порог кластеризации калибруется на своих данных. Публичных цифр DER для sherpa-onnx не нашли. Для ориентира: pyannote 3.1 — DER около 11% на VoxConverse.
- **Облако:** OpenAI `gpt-4o-transcribe-diarize` — распознавание и говорящие одним запросом, только Transcription API, около $2,5 за 1M входных аудиотокенов ⚠. Ограничения на длину кусков и «известных говорящих» в источниках противоречат друг другу — проверить по документации OpenAI.
- **Свой сервер владельца:** WhisperX и pyannote — сетевой сервис. Нарушает правило «без своего бэкенда», но годится для владельца.

## Решение
- Трейт `Diarizer` в ядре (сегменты по времени → метки говорящих) и отдельный трейт итогового распознавания с временем фраз.
- Реализации релиза 1:
  1. **Локальная** — sherpa-onnx, по умолчанию.
  2. **Облачная** — OpenAI-совместимая диаризованная расшифровка (`gpt-4o-transcribe-diarize`) как отдельный движок созвонов: распознавание и говорящие из одного ответа.
- Свой сервер — позже, если локальной точности не хватит.
- Перед выбором — прототип на синтетическом наборе (ТЗ, разд. 8): DER, скорость на CPU, размер моделей, лицензии моделей.

## Ограничение облачного пути (прожарка Б4)
Облачная модель принимает звук ограниченными кусками ⚠. Метки «Собеседник 1/2» в разных кусках не связаны между собой. До спайка облачная диаризация гарантирована только для дорожки собеседников, которая помещается в один кусок; длиннее — локальная диаризация (П-5). Спайк проверяет:
- реальный предел куска;
- поддержку «известных говорящих» по эталонным фрагментам ⚠;
- связывание кусков по эмбеддингам sherpa-onnx.

## Субтитры
Субтитры используют отдельный «движок субтитров» — только распознавание (ADR-005, ВФ-45). Диаризованный облачный движок для субтитров не используется.

## Последствия
- Модели диаризации скачиваются по требованию, как модели whisper. Размер и лицензии — в ВН-09.
- Облачный движок отправляет звук собеседников провайдеру. Пользователь выбирает это сам, в настройках есть явная подпись.
