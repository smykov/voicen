# ADR-005. Живые субтитры: квазипоток по VAD-фразам на существующих движках

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **принято владельцем** — субтитры в релизе 1; **предложено** — способ

## Контекст
В Voicen нет потокового распознавания, оно записано как «вне рамок». Есть движки пакетного распознавания (API, whisper.cpp, локальный сервер) и VAD Silero (задача T-102).

## Решение
- Каждая дорожка делится VAD на фразы. Фраза закрывается после паузы от ~600 мс или принудительно через 8–10 с речи. Каждая фраза распознаётся **движком субтитров** (только распознавание: API, встроенный или локальный сервер; ВФ-45), результат идёт в окно с подписью по дорожке (ADR-003).
- Очередь распознавания своя для каждой дорожки. Порядок показа — по времени начала фразы.
- Частичных результатов («печатает на ходу») в релизе 1 нет. Цель задержки — критерий 3 ТЗ.
- Потоковые модели (Nemotron streaming, Realtime API) и частичные результаты — следующий шаг, если не выдержим задержку. Интерфейс закладываем так, чтобы потоковый движок встал без переделки окна.

## Альтернативы
- **Realtime API провайдера.** Меньше задержка, но нужен новый тип движка и постоянный поток в облако.
- **Локальная потоковая модель.** Нужна новая модель и рантайм; качество на русском не проверено.

## Последствия
- Субтитры и итог распознаются раздельно (ADR-006). Стоимость API за время субтитров добавляется к стоимости итога.
