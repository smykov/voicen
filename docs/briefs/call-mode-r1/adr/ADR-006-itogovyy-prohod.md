# ADR-006. Итоговый транскрипт — отдельный проход после остановки

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **предложено**

## Контекст
Короткие фразы для субтитров распознаются хуже: мало контекста, обрывы на 8–10 с. Если субтитры выключены, живого текста нет вообще. Итог должен быть качественным и с временем фраз.

## Решение
После остановки записи:
1. Каждая дорожка целиком распознаётся движком созвонов: длинные куски по VAD-границам, время фраз (сегменты или слова).
2. Дорожка **system** диаризуется (ADR-004). Если движок облачный и диаризованный — говорящие берутся из его ответа.
3. Реплики обеих дорожек сливаются по времени (ВФ-42). Сохраняются `transcript.json` и `transcript.md` (ADR-009).

Текст живых субтитров в итог не идёт.

## Последствия
- Итог появляется не сразу (критерий 4 ТЗ). В списке видно состояние «Расшифровка…».
- Есть «Расшифровать заново» — например, другим движком.
