# ADR-003. Говорящие: дорожка задаёт роль, диаризация — только для собеседников

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **принято владельцем** — диаризация обязательна; **предложено** — способ

## Контекст
Владелец требует диаризацию. Общая диаризация смешанного звука ошибается чаще, особенно на «я против собеседника» и при перебиваниях.

## Решение
- Все реплики дорожки **mic** — говорящий **«Я»** (`me`), без модели.
- Дорожка **system** диаризуется (ADR-004) и делится на **«Собеседник 1…N»** (`s1…sN`).
- В живых субтитрах подпись — по дорожке: «Я» / «Собеседник». Номера собеседников появляются только в итоге.
- Пользователь переименовывает говорящих в пределах созвона (ВФ-52). Узнавание по голосу между созвонами — голосовые профили, следующий релиз, по согласию .

## Последствия
- Главная ошибка — «я против собеседника» — практически исчезает, если нет эха (ADR-008).
- Если с моей стороны в одну гарнитуру говорят двое, оба получат «Я». Это принятое ограничение релиза 1.
