# ADR-009. Хранение созвона: папка, форматы, восстановление после сбоя

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **предложено**; режим «только субтитры» без записи — **принято владельцем**

## Решение
**Папка** — `%LOCALAPPDATA%\Voicen\calls\<ГГГГ-ММ-ДД_ЧЧММСС>\`. Корень можно сменить в настройках.

**Во время записи** `mic.opus` и `system.opus` пишутся **постепенно** (Ogg Opus) со сбросом страниц на диск не реже раза в 10 с, плюс `meta.json` в состоянии `recording`. Было: куски PCM и сборка в конце — 4 часа PCM обеих дорожек ≈ 920 МБ временно (прожарка Б9).

**После остановки:**
- `mic.opus` и `system.opus` закрываются (Ogg Opus, моно 16 кГц, около 16–24 кбит/с);
- `transcript.json`, `transcript.md`;
- `meta.json` в состоянии `ready` или `failed`.

**`transcript.json`** (версия схемы 1):

```json
{ "schema": 1, "call_id": "...", "title": "...", "started_at": "ISO-8601", "duration_ms": 0,
  "speakers": [{"id": "me", "name": "Я"}, {"id": "s1", "name": "Собеседник 1"}],
  "segments": [{"start_ms": 0, "end_ms": 0, "track": "mic|system", "speaker": "me|s1",
                "lang": "ru", "text": "..." }],
  "engines": {"transcription": "...", "diarization": "..."} }
```

**Восстановление.** При запуске папка в состоянии `recording` → дописанные Ogg-страницы читаются, файлы корректно закрываются, состояние `recovered` (ВФ-22).

**Режим «только субтитры».** Ничего не пишет на диск. Звук фразы живёт в памяти до получения текста.

**Логи** — без текста и звука (правило Voicen). В лог пишутся только длительности, размеры, события устройств и коды ошибок.

## Последствия
- Нужен кодировщик Opus — зависимость с согласия владельца.
- JSON — точка входа для агентов и будущих интеграций: ecosystem-bots, итоги. Схема версионируется.
