# ADR-012. Язык: определение по фразе и «основной язык» под перевод

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **принято владельцем** — перевод в релизе 2 по основному языку; **предложено** — хранение в релизе 1

## Решение
- Язык распознавания для созвонов по умолчанию — **автоопределение по каждой фразе**. Если движок возвращает язык, он хранится в `segment.lang`.
- В настройках появляется **«основной язык»** (по умолчанию — язык интерфейса). В релизе 1 он только хранится. В релизе 2 субтитры фраз на другом языке получают перевод на основной язык (решение владельца).
- Если автоопределение ошибается на коротких фразах, можно жёстко задать язык созвона (Should).

## Последствия
- Релиз 2 строится без изменения данных: язык уже есть у каждой реплики.
