# ADR-010. Согласие собеседника и честность записи

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **принято владельцем** 21.10.2026 (ВВ-6)

## Контекст
Запись разговора и голос собеседника — его персональные данные. Правила разные:
- **РФ** — 152-ФЗ: нужно согласие;
- **Армения** — HO-49-N: согласие письменное или электронное, есть практика штрафов за запись разговоров с клиентами;
- **ЕС** — GDPR, местами нужно согласие всех сторон;
- **Швейцария** — nDSG.

Voicen не может сам уведомить собеседника: в звонок он не встраивается.

## Решение
- Запись всегда видна пользователю: индикатор и значок трея (ВФ-05). Режима «запись втайне» нет.
- При начале записи — напоминание «Предупредите собеседника о записи», его можно отключить (ВФ-06).
- В документации — что пользователь сам отвечает за согласие собеседников, и примерная фраза для начала созвона.
- Журнал согласий и голосовые профили — вместе в следующем релизе, по отдельной схеме с согласием.

## Последствия
- Юридическая ответственность остаётся на пользователе. Для B2B-оболочек в будущем понадобится журнал согласий.
