# ADR-008. Эхо без наушников: подавление на дорожке микрофона

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **предложено**

## Контекст
Без наушников голос собеседника из колонок попадает в микрофон. Тогда реплики собеседника задваиваются как «Я», а субтитры дублируются.

## Решение
1. **Подавление эха (AEC)** на дорожке mic, опорный сигнал — дорожка system: WebRTC AEC3 через крейт обработки звука WebRTC (например, `webrtc-audio-processing`) ⚠ — проверить сборку под Windows и лицензию BSD. Включено по умолчанию, можно выключить (ВФ-14).
2. **Фильтр дублей** в итоге: реплика «Я», совпадающая по времени и тексту с репликой собеседника выше порога, помечается и скрывается. Пользователь может её показать.
3. **Подсказка** в напоминании о записи: «Лучше в наушниках».

## Последствия
- Новая нативная зависимость — нужно согласие владельца и проверка в CI на Windows.
- Если AEC не соберётся в разумное время, релиз выходит с фильтром дублей и подсказкой, AEC уходит в следующий релиз.
