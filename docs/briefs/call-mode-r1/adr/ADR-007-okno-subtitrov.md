# ADR-007. Окно субтитров и индикатор записи — окна-оверлеи оболочки

Дата: 21.10.2026 · Релиз: режим созвона 1 · Статус: **предложено**

## Контекст
В Voicen **уже есть** окно-оверлей диктовки (T-053, T-065 DONE; T-057 поглощена T-065): окно без активации, один поток оверлея, жизненный цикл окна, проверка в установочном смоук-тесте. Субтитрам нужно окно поверх всех, без перехвата фокуса, перемещаемое, с режимом «клики насквозь».

## Решение
- Окно субтитров и индикатор записи — окна Tauri с признаками «поверх всех», «без активации» (`WS_EX_NOACTIVATE`) и по запросу «прозрачно для мыши» (`WS_EX_TRANSPARENT`). UI на Svelte, данные через IPC-события.
- Индикатор записи — на основе готового оверлея диктовки.
- Окно субтитров — новое окно того же механизма, но **интерактивное**: перетаскивание, изменение размера, кнопки переключателей. Сочетание «без активации» и перетаскивания проверить спайком первым. Предикат установочного смоук-теста (T-065) должен учитывать новое окно.
- Запасной вариант, если не выйдет без активации: обычное окно «поверх всех», фокус возвращается в прежнее окно.

## Последствия
- Полноэкранные игры и эксклюзивный полноэкранный режим могут перекрывать окно — ограничение релиза 1.
