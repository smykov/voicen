- **I1 moved to `core-test-os-answer.sh` with a word boundary after `.invalid`**: accepted. The contract change has two sides:
  - `.invalid_x` is now accepted;
  - `.invalid-x`, a `.invalid` with no name before the dot, any case, and comments are now refused.

  This is recorded in the guard-table row and in core-tests.md. The array form `([127, 0, 0, 1], 1)` was dropped from the regex as a syntax model and is listed as Not caught.
- **`*` entries**: acceptable for the existing deny and allow lines. See #4 for the limit.
