Tools: Serena was loaded but not used for `src-tauri/tests/call_indicator.rs`. It is a `#![cfg(windows)]` file, unindexed on the Linux host (T-267 review), so I read it with grep and sed. Nothing was built or run here: every result below is "expected, not run: Windows CI only".

**Frame.** No test fails when `s4_driver` clicks and waits after a failed `before` poll (T-267 r1#1; T-267 bite row "Acceptance 2, bound"). The never-paints test should bite that.

**Timeline of the never-paints test** (the watchdog starts after `serial()`):

The follow-up's claim fits M2, not the literal deletion M1. T-267's predicted message for "drop the early return" (`the click did not reach the page`) is wrong for today's page, though that mutant is still red.

**Hypotheses.**
1. The fixture answers the click. Confirmed: `LatePage::html` adds the listener for every `paint_after`.
2. A second path handles the same bound. Refuted: `s4_driver` has only the three s4 callers, and the other `wry_rig` users use `Page`.
3. The class was fixed before. Same `toothless-test` task class as F-024, but another mechanism. Not a recurrence, and not F-036's class.
4. The watchdog margin is too thin. Refuted: the driver ends at least HANG + SETTLE after the `before` poll fails, past the watchdog's 240 s by at least 2 s plus setup.

**Flake (F-036, F-037).** The green path polls a white body that never comes near PAGE_RGB and returns before any click. The listener change affects only code that runs after a click. The page of the existing test is swapped, so there is no new wait and no CI time. F-037 shares no code with this test.
