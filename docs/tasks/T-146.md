## Context

US5 (recover from a failed final pass), US5 #1–#7. Spec FR-027, FR-028, FR-037 (cancel). Area core, seam the queue part of `crates/voicen-core/src/call/final_pass.rs`. Needs the pass (T-138) and recovery (T-144).

## Acceptance

- [ ] Passes run one at a time, FIFO; a call stopped during another's pass is Queued and starts after it (T062, T063)
- [ ] Recording is allowed during a pass (T062)
- [ ] "Transcribe again" on a `failed` call redoes only the failed track; on a `ready` call it clears and redoes both; speaker names are kept (T062)
- [ ] Failure branch: a 401 gives `failed: key`; after the key is fixed a retry succeeds (T062)
- [ ] Deleting a transcribing call cancels the pass first (cancel token) (T062)
- [ ] Exit or crash during a pass restarts it at the next start (T062)
- [ ] Failure branch: `transcribe` on a `recording` call is refused as `recordingCall` (T062)
- [ ] Test that fails without the change: the queue tests of `call/final_pass.rs`
