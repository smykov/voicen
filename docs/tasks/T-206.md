Owner decision #265. Contour run 42871509840 ("teamwright agent T-062 analyze (hop 1)") failed in step "The stage" (`claude -p "/teamwright:analyze T-062" --max-turns 200 ...`) with exit 1 after ~17 min, committed nothing, and left no transcript: step "Keep the session for analysis" (`.github/workflows/teamwright-agent.yml` :287) copies to `RUNS_DIR=/srv/gha-voicen-runs` (:61), which does not exist in the ephemeral runner container, so it exits 0 silently (:292).
