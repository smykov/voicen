## Context

Owner, 2026-10-07: long dictations and the internal Whisper server need configurable limits. Decision #97 changes FR-24 from fixed timeouts to settings whose defaults are today's values: connect 5 s, transcription via API 30 s, via local server 60 s, post-processing 15 s, built-in engine 120 s. `docs/requirements.md` FR-24 is updated in the same task.

## Acceptance

- [ ] The settings hold the timeouts with the FR-24 defaults. They are validated within sane bounds (the analysis proposes the bounds), editable in the settings window (en/ru), and applied to the next job without a restart (P-013).
- [ ] Failure branch: an out-of-range value is refused on save with a field error, and nothing is saved; a job that exceeds the configured timeout fails with `failure=timeout` as today.
- [ ] `docs/requirements.md` FR-24 and the spec contracts are updated.
- [ ] Test that fails without the change: named in `## Tests`.
