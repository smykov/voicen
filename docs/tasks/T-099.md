## Investigation

See `docs/tasks/T-017.md` (analysis and Investigation): this task is its native part, moved here by decision #130.
### Refresh after T-098 (2026-10-17)

**Tools.** Serena and context7 were not reachable in this session. I used grep and file reads in the repo, and read the crate sources whisper-rs 0.16.0, whisper-rs-sys 0.15.0 (whisper.cpp 1.8.3), cmake 0.1.57 and tauri-build 2.7.1 as downloaded `.crate` archives. Both whisper crates are still the latest releases.

**Trait fit (no drift).** `contracts/core-traits.md` matches the code in `engine/speech_model.rs`. `SpeechModel: Send` is satisfied by whisper-rs's `unsafe impl Send` on `WhisperState`. `ModelResidency` already covers three things: the missing-file case (gives `NoLocalModel`), the non-`lmgg` case, and load timing. So the loader needs no file checks of its own. Remaining cases the loader still has to handle:
- A truncated file with a valid magic fails in `whisper_model_load` ("not all tensors loaded"). whisper-rs reports this as an `InitError`, which must map to `LocalEngineFailed`.
- Garbage in the header stays the accepted risk R-8.
- On Windows, `path_to_bytes` needs the path to be UTF-8. whisper.cpp then widens it on MSVC.
- whisper-rs `set_abort_callback_safe` leaks its boxed closure: one `Abort` clone per transcription. The leak is small but unbounded. Two ways out: accept it and note it in the crate doc, or use the raw `set_abort_callback` with a closure stored on `WhisperModel`. This is the developer's choice; the reviewer checks it.

**Q1 — owner question (not decided here).** Decision #132 (c) asks for `GGML_CPU_ALL_VARIANTS`. In ggml this option needs `GGML_BACKEND_DL`, and `GGML_BACKEND_DL` needs `BUILD_SHARED_LIBS=ON` (ggml/src/CMakeLists.txt). whisper-rs-sys 0.15.0 blocks this in three ways:
- `build.rs` hard-codes `BUILD_SHARED_LIBS=OFF`. Its env pass-through accepts only `WHISPER_*`, `GGML_*` and `CMAKE_*` variables, so the setting cannot be overridden.
- It links `static=ggml-cpu` and the other libraries statically.
- whisper.cpp never calls `ggml_backend_load_all`, so with dynamic backends the app would also have to load them itself, and the installer would have to ship whisper/ggml/ggml-base plus about 9 `ggml-cpu-*.dll`.

Options for the owner:
- (i) Keep (c): a patched or vendored whisper-rs-sys (`[patch.crates-io]`), plus the backend load call, plus shipping the DLLs in NSIS. This crosses into the installer and T-017, and touches the NFR-09 size limit.
- (ii) Supersede #132 with a static baseline:
  - `GGML_NATIVE=OFF` alone enables SSE4.2/AVX/AVX2/BMI2 (FMA/F16C implied on MSVC), so CPUs without AVX2 fail with an illegal instruction.
  - Alternatively, also switch AVX2/BMI2/FMA/F16C off for an SSE4.2/AVX floor, which is slower.
- (iii) A project-owned sys crate.

Until the owner answers, the GGML-flags Acceptance line cannot be met as written.

**CRT (F-001 class, CI-blind premise).** The shell's tauri `static_vcruntime` sets `/NODEFAULTLIB` for msvcrt, vcruntime and ucrt (debug and release) and `/DEFAULTLIB` for libcmt, libvcruntime and ucrt. It does not exclude `msvcprt`. cmake-rs adds cc-rs's `-MD` unless `CMAKE_<LANG>_FLAGS` is already defined. whisper.cpp's `cmake_minimum_required(3.5)` leaves CMP0091 OLD, so `CMAKE_MSVC_RUNTIME_LIBRARY` is ignored unless `CMAKE_POLICY_DEFAULT_CMP0091=NEW` is set.

The GitHub runner has the VC redistributable installed, so the install smoke would pass even if voicen.exe imported MSVCP140.dll. The proof is therefore a `dumpbin /dependents` assertion, not a smoke test. Levers to try on wip CI:
- `CMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded` together with `CMAKE_POLICY_DEFAULT_CMP0091=NEW`;
- defining `CMAKE_C_FLAGS`/`CMAKE_CXX_FLAGS` explicitly, which stops cmake-rs adding `-MD`;
- test exes of voicen-whisper get the shell's link arguments through `rustc-link-arg-tests` (F-002 precedent).

An open item already exists: W2 in `docs/decisions/ci-toolchain.md` (aws-lc is built /MD).

**Stale build cache.** whisper-rs-sys has no `rerun-if-env-changed` for `GGML_*`/`CMAKE_*`. rust-cache's restore key covers only env prefixes `CARGO CC CFLAGS CXX CMAKE RUST` and falls back to the previous key. So a GGML flag change can reuse a stale OUT_DIR. The CI assertion must read the effective `CMakeCache.txt`, or the rust-cache step gets a `key:` (that is a fragment edit).

**make check tripwires.**

A new workspace crate touches:
- `Cargo.toml` members and `Cargo.lock`, then `make licenses` (whisper-rs and whisper-rs-sys are Unlicense, accepted in #9; whisper.cpp is already in `licenses/manual.json`).
- `scripts/ci/version-stamp.sh` `lock_version`, which stamps only voicen and voicen-core. A third member with `version.workspace = true` would keep its stale lock version. The Windows cargo calls have no `--locked`, so this breaks the script's "--locked" contract silently. Two fixes: stamp every source-less `[[package]]` (also update `version-stamp.test.sh` and the ci.yml comment "two workspace members"), or give voicen-whisper a fixed version.
- `scripts/ci/clippy-lines.txt`: every new line containing "clippy" in a Makefile, a `.rs` file or the crate's `Cargo.toml` needs an owned entry. The `*` deny-attribute entry can be reused.
- Linux gate coverage: `check-core` is `-p voicen-core` and `check-shell-windows` is `-p voicen`, so nothing covers the new crate until T-017. A `DOCS_RS=1` fmt/clippy step needs a ci-toolchain decision entry. That file says a gnu-only build failure must not be silenced by a switch without a recorded decision.
- The Windows `cargo test --workspace --exclude voicen` (ci.yml) picks the crate up automatically. It stays separate from voicen (F-001 rule) and adds native build time.

A new CI cache step touches:
- release-guard R11: the restore step can reuse the owned line `        uses: actions/cache/restore@v6`. The save step is a new byte-identical fragment `scripts/ci/cache-steps/windows-tiny-model-save.yml`, with these rules:
  - name characters limited to `[A-Za-z0-9 ()._-]`;
  - line 2 must be `if: ${{ github.ref == 'refs/heads/main' && ... }}`;
  - no `||`;
  - the last line is the next step's `      - ` line.
- No comment may name an action.
- No secrets/vars (R4) and no column-0 line (R12).
- The cache key is the catalog commit `5359861c…` plus the sha.

Not touched by this task: `shell-targets.txt`, `helper-windows.txt`, `check-shell-layout`.

**CI premise (P-016).** wip runs never save the cache, so every wip run downloads the 75 MB tiny model from Hugging Face. An outage gives a red run that the diff did not cause; it must be logged as its own task or F-entry.

**Fixture.** `crates/voicen-core/assets/connection-test-speech.s16le` is about 1.02 s of 16 kHz s16le audio (CC0, already in `licenses/manual.json`). That is above whisper.cpp's 100 ms minimum. Unproven premise: that tiny transcribes it to "speech bubble". An optional native Linux probe outside the gate would settle it before the first wip run.

**Size verdict.** One crate seam plus CI wiring, so no spec tool is needed, provided Q1 is answered with a static baseline (ii). If the owner keeps (c), the work crosses into the installer and the bundle size limit and needs a split or a spec 002 amendment.

**Recurrence.** `docs/failures.md` has no entry of class `local-engine`. Related classes to watch: ci-toolchain (F-001 CRT, F-002 test-exe link config, F-011) and ci-premise-unchecked-before-main (P-016). `recurrence_of` stays `[]`.
