## Context

Split from T-089 by owner decision #129 (option a): the behaviour-neutral clock seam lands first; T-089 (bans, canary, token guard, I1) depends on it.

## Acceptance

- [ ] Every `Instant::now()` and `.elapsed()` on an `Instant` in `crates/voicen-core/src` outside `clock.rs` goes through `crate::clock::instant()` / `since()`
- [ ] `make check` and all core tests are green with no guard or gate change
- [ ] Failure branch: an integration test under `crates/voicen-core/tests` cannot call `crate::clock::instant()` (`pub(crate)`) and keeps `tests/common::timing` — verified by the build
- [ ] Test that fails without the change: none (behaviour-neutral refactor); the count of direct clock reads outside `clock.rs` goes from 71 to 0

## Tests

- Count, `grep -rnE 'Instant::now\(\)|\.elapsed\(\)' crates/voicen-core/src | grep -v src/clock.rs | wc -l`: before 73 → after 0. The 73 were 72 call sites (69 `Instant::now()`, 3 `Instant::elapsed()`: `connection_test::run`, `Pipeline` post-processing timer and `text_to_paste_ms`) plus 1 module doc comment in `test_support/realtime.rs` (reworded to name `crate::clock::instant()`); the analysis's 71 was a shorter count of the same sites. Every hit was an `Instant`; no `SystemTime` read matched (the `SystemTime::now` in `test_support::unique_dir` and `clock::SystemClock` are not in scope). The wider `Instant::now|\.elapsed\(` (no parentheses, e.g. `map(Instant::now)`) also gives 0 after. `saturating_duration_since` between two stored `Instant`s is arithmetic, not a clock read, and stays.
- Core: `scripts/tw-run core -- cargo test -j2 -p voicen-core --all-features` — 755 passed, 0 failed, 0 ignored; existing tests unchanged (behaviour-neutral: `clock::instant` is `Instant::now()`, `clock::since(t)` is `t.elapsed()`).
- Lint: `cargo fmt` clean; `cargo clippy -p voicen-core --all-targets [--all-features] -- -D warnings` clean (five now-unused `Instant` imports removed).
- Gate: `make check` — exit 0; cargo 755 passed; vitest 159 passed; Playwright 236 passed, 3 skipped (the scenario-gated `netns-probe` / `build-race` specs, skipped by design); node tests 68 passed; no tracked file changed by the gate.
- Failure branch: an integration test under `crates/voicen-core/tests` cannot call `clock::instant()` / `since()` — both are `pub(crate)`, so the compiler refuses it (E0603 private function); the integration tests keep `tests/common::timing` and were not touched.
- CI: https://github.com/smykov/voicen/actions/runs/38863479478 @ aff99cc — green full `ci.yml` on `wip/T-103` (Gate and Windows build/install/smoke success). The earlier run 38862092976 @ 9e5e063 was cancelled by the push of aff99cc (Gate success, Windows job cancelled; not a red attempt). `make check` green at aff99cc after the review 1 docs fixes.
