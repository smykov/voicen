## Context

Split from T-004 by decision #38 (T-004 analysis, option A). The shell decides the startup action (`settings::gate::startup_action` over the `LoadOutcome` that `run()` keeps as `_load_outcome`, src-tauri/src/lib.rs) but never carries it out, and `tauri.conf.json` opens a static `main` window at every start. This task adds `src-tauri/src/settings_window.rs` with `open(tab, field)` as the only way to create the `settings` window (at most one; a second `open` focuses it and emits `settings://focus`), the startup executor on `RunEvent::Ready` in `run()` as a function the tests call directly, `app.windows: []` in `tauri.conf.json`, and the capability moved to the `settings` label (event listen, `core:window:allow-destroy`). Findings from the T-004 analysis: tauri checks every `plugin:*` command against the window label; destroying the last window exits the app unless prevented (`prevent_exit` belongs with T-006's tray — until then closing the first-run window ends the app, accepted interim, #38); `setup` never runs from `build_app`. Shell tests follow the layout rule (#36/#37: only `src-tauri/tests/*.rs`). The `outcome=` log line is T-008's.

## Acceptance

- [ ] Windows CI: `OpenSettings(Engine)` from a FirstRun outcome creates exactly one `settings` window at `settings?tab=engine`; `TrayOnly` (Loaded) creates none; a second `open` leaves one window and emits `settings://focus`
- [ ] The `settings` window may listen to `settings://changed` and close itself (capability check); no window is created from `tauri.conf.json`
- [ ] Install smoke: first launch shows a visible settings window; a launch with a loaded settings file shows none
- [ ] Failure branch: a startup outcome of `Unavailable` opens the window (with `unavailable` set in the view) and no save succeeds — Windows CI test over `load_settings` with an unreadable file
- [ ] UI side of `open(tab, field)` (left out of T-004, decision #38 Q2): the `/settings` page focuses the input with `data-field=<field>` from `?field=` and on `settings://focus {tab, field}`; closing the window with a dirty draft asks to discard (Playwright, mocked IPC)
- [ ] Test that fails without the change: `src-tauri/tests/settings_window.rs` (Windows CI) and the install-smoke window check
