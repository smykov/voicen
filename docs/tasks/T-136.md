## Context

US2. Spec FR-022, FR-024, FR-025, FR-029; research R10. Area core, seam `crates/voicen-core/src/engine/openai.rs` (`transcribe_timed`, `ResponseShape`, `Timed`, the language table), tested against wiremock. No call-mode prerequisite.

## Acceptance

- [ ] A `Segments` request sends `response_format=verbose_json` and `timestamp_granularities[]=segment`; an OK reply parses its segments (T042, T043)
- [ ] Failure branch: a 400 or 422 to `Segments`, or a 2xx without `segments`, is time-less; a 400 on `Plain` is `provider` (T042)
- [ ] Failure branch: 401 and 403 map to `key` and never fall back; a connect error maps to `network`; a late answer under the FR-24 timeouts maps to `timeout`; 429, other 4xx/5xx and a malformed body map to `provider` (T042)
- [ ] The response cap stays 1 MiB and the `engine::http` bans hold (no `Response::json()`, no `bearer_auth`) (T042)
- [ ] "english", "English" and `en` map to `en`; an unknown value maps to `null`; the request carries the dictation speech language (T042)
- [ ] Test that fails without the change: the `engine/openai.rs` wiremock tests
