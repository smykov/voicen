## Context

Session review of 2026-10-23 (T-116). `developer-core` ran 35 min, about 29 of them waiting on `make check`: the first full run stopped at `check-clippy-lines` after ~3 min on a no-op `#![allow(clippy::…)]` line the test-writer had committed in the red tests (53190cd), then a `make -k check` ran ~19 min (a full gate normally takes ~10 min; the first libopus builds for the native and mingw targets and the two 60-minute size tests likely added to it). The test-writer then had to be resumed to delete the line, and the orchestrator ran the full gate again.

A seconds-long tripwire found what a test-writer pre-check would have found before handover. Note: adding a Makefile target is a guard change (`checker: true` + `analysis.decides_on`, `make check-guard-trigger`); the analysis decides whether existing targets suffice.

Seam candidates: `.claude/agents/test-writer-*.md` (before handing over), `.claude/agents/developer-*.md` (targeted tests first, one full gate at the end), possibly the kit template (render drift).
