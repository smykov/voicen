**test-guard (read, `scripts/hooks/test-guard.sh` `builtin`, `config_matchers`, `allowed_in_run`).**
- Refused: `make check` and `make -k check` (the positional `check`).
- Not refused: `make check-<x>` (the regex `(test|tests|check)|test[-_:].*` must match the whole word, and the prefix matcher compares whole words); `scripts/tw-run core -- '<lint_command>'` (exact lint_command); `scripts/ci/*.sh`.

- Side finding, static reading only: a command that starts with `systemd-run` (the owner's host-load form from 2026-10-24, passed in spawn prompts) is neither stripped as a prefix nor treated as a runner, so `systemd-run … make -k check` passes the guard and bypasses tw-gate's cache.
