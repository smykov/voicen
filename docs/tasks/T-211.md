## Context

Part 4 of the T-007 split (decision #274). From T-051 review round 1 (#2): the dictation session's FIFO worker can die on a panic in `Pipeline::run_job` (unwind builds: tests, dev); `dictation.rs` then drops every later job (`let _ = queue.send(job)` in `stop_recording`), the overlay stays on Processing and nothing is shown or logged. Detection seams named by the T-007 analysis: a drop guard in `run_worker` (like `StopInFlight`) that marks the worker dead under the lock, clears `queued`, shows the notice and writes a log line; and the `send` result in `stop_recording`. Depends on T-007, which adds the `Notifier` the notice reaches.

Owner decisions (#274): Q1 (a) — new catalog id `failure.internal` (en "Dictation stopped because of an internal error. Restart Voicen.", ru "Диктовка остановилась из-за внутренней ошибки. Перезапустите Voicen."), on the overlay and as a toast; the tray Error state stays until restart (the menu-open rule does not clear it); every later press is blocked with the same notice, so no audio is recorded only to be dropped; one `warning kind=dictation_worker_stopped` line. It is not a `FailureReason`: it belongs to no job and cannot be retried. Q2 (a) — release builds keep `panic = "abort"`: a `run_job` panic ends the process; the crash file and the next start's previous-session verdict are the trace; no crash notice, no watchdog.

## Acceptance

- [ ] Core: a worker that ends (panic in `run_job`, unwind build) → `failure.internal` shown once through the Notifier and the overlay, tray Error, one `warning kind=dictation_worker_stopped` line — red test with a pipeline fake that panics
- [ ] Core: after that, a press records nothing and shows `failure.internal` again; the tray Error is not cleared by opening the menu
- [ ] Failure branch: the worker dies while a job is queued → the queued job is dropped with the notice, `queued` cleared, overlay leaves Processing (not left hanging)
- [ ] `i18n` catalog (en, ru) has `failure.internal`; `contracts/messages.md` lists it
- [ ] `docs/decisions/dictation-session.md` Open line on `run_job` panics amended per Q2 (a)
- [ ] Test that fails without the change: `crates/voicen-core` dictation session tests
