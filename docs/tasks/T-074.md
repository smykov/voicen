## Context

Follow-up 1 of decision #91 (T-020 is the core path only). `start_dictation` in `src-tauri/src/dictation.rs` constructs `Arc::new(PassThrough)`. This task installs `ChatPostProcessor` there, so an enabled post-processing step runs in the real app. OQ-14 was answered by #90, so the wip/CI path exists.

## Acceptance

- [ ] With post-processing enabled and configured, a dictation in the installed app is post-processed through the chat endpoint (Windows CI with a mock server).
- [ ] Failure branch: when the post-processing server refuses, the raw transcript is still delivered and the skip reason reaches the session (tray Error), proven on Windows CI.
- [ ] Test that fails without the change: named in `## Tests`.
