## Context

A new parallel worktree needs `.serena/project.yml` and `.serena/memories` copied from the main tree by hand before `tw-parallel.py prepare`; without them the worktree's stage sessions cannot use the context tool. `tw-parallel.py` belongs to the plugin, so the fix sits on the project side, or becomes a teamwright feedback line if the project has no seam for it. Check first whether the files should simply be tracked.

## Acceptance

- [ ] A worktree started with `tw-parallel.py start` passes `tw-parallel.py prepare` with no manual copy
- [ ] Failure branch: when the config is missing, `prepare` or the project's own step says so by name and the worktree is not launched
- [ ] Test that fails without the change: named under `## Tests`, or the seam is recorded as the plugin's and the feedback line drafted
