## Context

Three small core seams: `local_models/residency.rs` (drop on stale), `crates/voicen-core/build.rs` (commit selection as a pure function) and the `clock.rs` module doc. Carries T-060 lines T-098 v2#1, T-023 (ii), T-103 r3#1. Red test first: for v2#1, a gated load plus `on_engine_or_model_changed(Some(other))` gives `dropped() == 1` after the guard drops. The analysis may split it into three tasks.

## Investigation

Tools: Serena loaded. `get_symbols_overview` on `residency.rs` worked, but `find_symbol` returned `[]` for `ModelResidency/acquire` and the other impl-method name paths, so the method bodies, the tests and `build.rs` were read with grep/sed. Context7 `/websites/doc_rust-lang_stable_rustdoc` was used for the compile_fail error-code rule.

**Frame.** No observed failure. These are three Low findings carried from T-060 P3d (T-098 v2#1, T-023 (ii), T-103 r3#1).

**Hypotheses.**
1. *(v2#1) The stale-acquire branch has no test.* Confirmed. The three `on_engine_or_model_changed` calls in the tests all run with no load in flight, and nothing in `tests/` mentions `stale`.
2. *(second path) The same concern on another path.* Confirmed for the residency: the prewarm worker's stale discard (`if stale { Some(model) }`) is untested too, so the task adds that test. Refuted for the commit: `build.rs` is the only producer and `build_info.rs` the only reader (grep over `crates/` and `src-tauri/` `*.rs`).
3. *(T-023 ii) The commit choice gives a padded or empty value.* Confirmed by reading `build.rs:8-19`: the trim is used only in the blank check, and git output that succeeds but is empty gives `""`. Not reproduced in CI, where `git rev-parse` always prints a hash.
4. *(r3#1) The E0603 code is not checked.* Confirmed by the rustdoc book: error numbers on compile_fail are nightly-only, and the toolchain is stable 1.99.
5. *(class fixed before) Recurrence.* None. `docs/failures.md` has no entry for compile_fail, build.rs commit selection or residency drop-on-release. F-024 is in the same `toothless-test` task class but has a different mechanism.

**Root cause, invariant, seam, approach.** See the `analysis` block.

**Size and blockers.** Not large: three single-file seams, no spec work needed, no owner decision, nothing blocking (`blocked_on` stays empty). Not a guard change (`checker: false`). Docs to update with the change: none beyond the `clock.rs` module doc. Add a `docs/decisions/core-tests.md` line only if the reviewer wants the compile_fail limit recorded per area.
