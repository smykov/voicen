## Investigation

Tools: Serena (`get_symbols_overview`, `find_symbol` on `call/capture.rs`); `find_referencing_symbols` on `Timeline/dropped` returned no symbol, so callers were found with grep (`session.rs` `step_of` and the writer's `Report::Dropped` arm; the test `a_full_channel_drops_blocks_fills_exact_silence_and_reports_the_drop`). rubato 5.0.1 from `Cargo.lock`, docs from context7 `/henquist/rubato`.

**Claim: confirmed.** `Timeline::dropped` writes `ms*16` zeros at `written` and then moves `conv.proc_pos` by the same amount. The converter still holds the audio between `written` and `conv.in_pos()`:
- the sinc delay: `output_delay = SINC_LEN * ratio / 2`, so 32 samples (2 ms) at 16 kHz and 10 samples at 48 kHz;
- the `fifo` remainder: `Converter::run` processes only full 10 ms chunks, so up to 159 output samples are left over.

That tail comes out after the zeros, shifted later by the dropped span. "Exact write position" means the next block's expected position (`Timeline::pos(at)`) is still compared with `in_pos`, and `in_pos` moved with `proc_pos`. So placement stays exact and only the tail is misplaced. The doc comment of `dropped` describes this order as intended. The existing test cannot see it, because it uses 0.5 on both sides of the drop. Its assertion `step.pcm.len() == 480` (all zeros) pins the buggy order.

**Hypotheses checked:**
- A second path: `lost`, `flush` and the rate change all call `retire` first, so they are correct. The `>40 ms` re-anchor and `advance_to` feed zeros through the fifo, so they are also correct. `dropped` is the only path that writes around the converter.
- Fixed before: no. `docs/failures.md` has no resampler, timeline or drop entry. The `docs/decisions/call-session.md` I7 rule only fixes `at_ms = written()/16`, read before `dropped`.

**Side note (not in scope):** after the fix the silence starts at `round(in_pos)`. That is up to the latent tail (about 2–12 ms) later than the I7 `at_ms` the writer logs. This is well inside whole-ms reporting and needs no change.

**Flush without changing the position accounting:** possible. `retire` emits exactly `round(in_pos) - written` samples, so `written` lands on the drop's start. The next block then re-enters through the fresh-converter path of `place`, which places it at its own stamp. This is one seam: `Timeline::dropped`.
