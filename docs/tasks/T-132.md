## Investigation

Tools: Serena (`find_symbol`; `CallSession/start` came back empty because `start` is a private method of an impl block, so I fell back to grep and `sed` on crates/voicen-core/src/call/session.rs); grep and file reads for ci.yml, the PowerShell helpers and the docs.

**Frame.** Observed: the install smoke proves the start line, settings load, reconcile, first-run window, tray and close. It never touches call mode. Expected (spec FR-043, contracts/installer-ci.md): the installed app on the device-less runner gets `--call record`, logs the no-output-device refusal and keeps running, leaves no call folder, adds no window and leaks nothing.

**Hypotheses.**
1. *The smoke has no call assertion*: confirmed. The step has no `call` text, and no other step passes `--call`.
2. *A second path already proves it*: partly. call_launch.rs AC2 proves the refusal with the real `CpalTrackSource` in a test rig, not in the installed exe. single_instance.rs proves that the switch opens no window. Neither is the "deployed" proof that FR-043 asks for.
3. *This class was fixed before*: not a recurrence (`recurrence_of: []`). Related classes the design must respect: F-003 (raw facts, a product window at start), F-008 `smoke-window-predicate` (the census reads the one manifest; the call indicator is a product window, never a helper), F-009 (credentials only through scripts/ci/credentials.ps1), F-006 (every external process is bounded: hence `WaitForExit(30000)`).
4. *The refusal leaves a folder*: refuted by code order. `open_tracks` opens the system track before `create_files`, and `create_files` is the only folder creator.
5. *Runner premise (no render endpoint)*: observed. The AC2 assertion `!has_output` passed in run 43598234999.

**Open items (none needs an owner product decision).**
1. Planted values. The plan (FR-042 row: "smoke log has no planted value") does not say what to plant. A refused start reads no key, opens no mic and has no transcript. So the useful plants are a tripwire fake key at a real slot target (`Voicen/transcription-api`, crates/voicen-core/src/secrets.rs) and the runner's own endpoint friendly names (FR-042 names them). If the runner has no endpoints, that list is empty, and the step prints the count so this is visible. This is a test-design choice, made here, not a product question.
