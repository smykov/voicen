## Context

This task comes from two T-017 review follow-ups, r1#1 (Medium, silent-degradation) and r1#2 (Medium, toothless-test) (`docs/tasks/T-017.follow-ups/r1.md`). The owner decided on 2026-11-23 to hold both in one task (/teamwright:sprint §1b).

When `SettingsService` is missing or the `start_model_idle` spawn fails, `run()` skips it with no log line (`src-tauri/src/lib.rs:575-577`). The idle unload (NFR-03) and the unload on a settings change (FR-012) then never happen, and nothing shows it. No test calls `start_model_idle` (`src-tauri/src/local_models.rs:125`): removing `on_settings` or `tick` from its loop, or its call in `run()`, leaves every test green. The shell is Windows-only: its tests live in `src-tauri/tests/*.rs` and run in Windows CI.

## Acceptance

- [ ] A missing `SettingsService` or a failed `start_model_idle` spawn writes one typed log event (closed fields, no free text, no transcript or key) and the app keeps running.
- [ ] A shell test drives `start_model_idle`: a settings change that drops the built-in engine unloads the resident model, and an idle period past the timeout unloads it.
- [ ] Failure branch: the test goes red when `on_settings` or `tick` is removed from the loop, or when `run()` no longer calls `start_model_idle` (bite check, cited under `## Tests`).
