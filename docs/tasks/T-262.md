## Context

Option 4 of #360. `ci.yml` `windows: needs: gate` serialises the two jobs on every ref. On `wip/**` (and the contour's `workflow_dispatch`) the Windows job should start at once; `main`, `v*` tags and the release job keep `needs` (release: `needs: [gate, windows]`). The windows job head is byte-pinned (`scripts/ci/windows-head.yml`, R15): change both together.

Measured 2026-11-24 (decisions #360): a `wip/<ID>` `ci.yml` run takes 52 min serial (gate 21 + windows 24-31; runs 45344541978, 45346473438, 45332192687); T-247 needed 4 wip rounds, T-151 3. Cost of the change: Windows minutes are spent also when the gate turns out red.

Guard paths (workflows, `scripts/ci/`, byte-pinned heads and fragments) change in pairs; `checker: true`, `analysis.decides_on` (P-020).
