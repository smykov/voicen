## Context

Cut from T-025 by decision #76. FR-034 / FR-28 v4: all app data, WebView2 included, lives under `%LOCALAPPDATA%\Voicen`, so the uninstaller's folder removal takes it too. tauri 2.12.1 `src/manager/webview.rs:559-564` uses `app_local_data_dir()` (`%LOCALAPPDATA%\dev.voicen.app`) when a window sets no `data_directory`; `settings_window::open` (settings_window.rs:83) and the overlay build (src-tauri/src/overlay.rs:347) set none. One helper (e.g. `paths::webview_dir()`) used by every window builder; depends on T-057 because it touches `overlay.rs`.

## Acceptance

- [ ] Windows CI: after the settings window and the overlay are opened, WebView2 data exists under `%LOCALAPPDATA%\Voicen\webview` and `%LOCALAPPDATA%\dev.voicen.app` does not exist
- [ ] Failure branch: a new window builder that does not use the helper fails a check (test or gate) — Windows CI / Linux gate
- [ ] Test that fails without the change: the Windows CI step / test named by the analysis
