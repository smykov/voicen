**2. Product points settled from the specs (no new OQ).**
- Privacy note: always visible on the tab (its text is already conditional: "When post-processing is on, …"); satisfies 003 US3-6 and FR-013 without a rule on engine or toggle in the UI.
- Fields stay rendered and editable while the toggle is off (004 FR-004 "kept as entered"; a disabled input would also break F focus and the R round trip).
- Key optional (003 FR-011): no `key.required` for post-processing.
- Tab order Engine, Recording, Output, Post-processing, History, General (004 FR-001).
- Base URL hint: do not reuse `settings.base_url.hint` (it promises `/audio/transcriptions`, #96, transcription only). Either no hint or a pp-only example hint without the full-endpoint sentence; the full-endpoint question for pp is already OQ-17 (open, non-blocking).
- Error codes: the existing `required`, `url.malformed`, `url.credentials` (004 data-model "plus 003's codes" adds none).
- Labels (agent wording, owner may revise in review): `settings.tab.post_processing` "Post-processing" / "Постобработка"; `settings.field.post_processing_enabled` "Improve the text with an LLM before pasting" / "Улучшать текст с помощью LLM перед вставкой"; `settings.field.prompt` "Prompt" / "Промпт"; `settings.field_label.post_processing.enabled` "Post-processing on" / "Постобработка включена"; `settings.post_processing.privacy_note` = 003 contracts/ipc.md text (en/ru).
