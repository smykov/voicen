**Wire details pinned here** (developer-level; written into contracts/ipc.md in the same commit; the owner may override them, none is blocking):
- **D1 Damaged summary.** `CallSummary` requires `title` and `startedAt`, but a damaged entry has no meta. Use the same default title a new call gets (`calls.title_default` from the stamp, UI language), `startedAt` = the stamp as local `YYYY-MM-DDTHH:MM:SS` with no offset, and `durationMs: null`. So `CallStore` wire builders take `UiLanguage`.
- **D2 `calls_get` on a damaged call** gives `ioFailed`; a folder that is gone gives `notFound`. The UI offers only Open folder and Delete for damaged rows.
- **D3 Detail lines.** No `transcript.json` gives `lines: []` (recording, queued, failed). One that is present but unparsable or fails `validate` gives `ioFailed`: showing it as empty would hide a broken transcript. Line `speaker`, `track` and `lang` are copied from the validated `SegmentV1`. `speakers` come from meta.json, the source of names (FR-035).
- **D4 `ioFailed.reason`** is the existing `UnwritableReason` snake_case word through `reason_of` (`missing`, `not_a_folder`, `access_denied`, `disk_full`, `other`; `relative` cannot come from an io error). This is the vocabulary `FieldError.reason` already uses (#196), and it avoids a second serialization of one enum. The camelCase rule covers field names and the listed `code`/`state`/`failReason` values. The UI text of each reason is T-143/T-128's job (no catalog ids exist for these reasons yet; grep of `i18n/en.json`).
- **Export without a transcript** (not `ready`) gives `ioFailed{reason: missing}`. The `{saved}` result and the save dialog are the shell's (T-142). Core takes the full `target` path from the dialog. A target with no parent or no file name gives `ioFailed{other}`. A target that is a directory fails at rename and gives `ioFailed`, leaving no tmp.
- **`wire_root`** is the path's UTF-8 text. A root that is not valid Unicode (possible on Windows) gets a lossy string that no wire value can match, so such a root lists but cannot be opened. That is accepted and noted in the decision record.
