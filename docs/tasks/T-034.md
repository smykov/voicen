## Context

Split from T-014 by decision #35 (T-014 analysis, option B). T-014 builds the `Autostart` trait, the save step with undo, `reconcile_autostart`, `WinAutostart` (HKCU Run value `Voicen`, data `"<exe>" --autostart`) and `launched_by_autostart(args)`. This task adds what needs the settings window (T-004) and the tray (T-006): the General-tab "Start with Windows" toggle over `settings_save` with its Playwright case (spec T059), and the logon behaviour — a start with `--autostart` opens no window, only the tray (FR-19; `startup_action` already returns `TrayOnly` for `Loaded`). A real logon can only be checked by the owner on Windows (SC-007 / spec T066): that needs a `verify_exception` the owner accepts — ask when this task reaches verification.

## Acceptance

- [ ] The General tab shows the toggle from `settings.start_with_windows`; switching it and saving sends `start_with_windows` through `settings_save` (Playwright, mocked IPC)
- [ ] Failure branch: `settings_save` returns `Refused` with `general.start_with_windows: autostart.failed` → the field shows the reason and the toggle returns to the saved value (Playwright)
- [ ] Windows CI: the installed exe started with `--autostart` and a loaded settings file opens no visible top-level window
- [ ] Owner, on Windows: with the setting on, after a real logon Voicen runs in the tray and no window opens
- [ ] Test that fails without the change: the Playwright case for the toggle and the Windows CI `--autostart` start check
