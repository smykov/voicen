## Context

From T-056 review round 1 (#2): T-056 (`deploys: false`, `surface: none`) gets no verify record, so "the GitHub time is recorded at verify" had no owner. The gate job does not cache `target/`, so `make check-shell-windows` builds cold on every CI run (locally 131 s, the spike 214–372 s), and the Windows job waits for the gate. Read the first CI runs after T-056 is pushed (`gh run view <id> --job <gate> --log`), record the measured cold time of the `check-shell-windows` step in `docs/decisions/ci-toolchain.md`, and decide (with the numbers) whether to add a `target/` cache to the gate job (actions/cache keyed on Cargo.lock + rust-toolchain + the image digest) or keep it cold. Any ci.yml change keeps F-001/F-002 rules (no `--doc`/rustdoc steps).
