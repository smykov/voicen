## Context

Completes the release-1 flow on Windows: FR-01 (tray, single instance), FR-02 (hold mode, < 0.3 s discarded), FR-04 (indicator; overlay never takes focus), FR-10 (clipboard with history exclusion, wait for modifiers ≤ 1 s, Ctrl+V into the start window, hotkey not passed on), FR-22 (Esc cancels only while recording), NFR-02 (mic opened on press). Shell code in `src-tauri` over the core pipeline from T-001. Also wires the settings subscribers that need the tray: tray menu rebuild and the notifier on `SettingsService::subscribe()` (moved from T-030 by decision #34). Also owns `settings_list_microphones` and the Recording-tab microphone field (decision #38), `prevent_exit` when the last window closes (the tray keeps the app alive), and routing tray / second-instance / engine-none requests to `settings_window::open` (T-037). Note from T-037 review round 1: `open` checks for the window and then builds it, so two concurrent callers on different threads get "already exists" instead of a focus — serialize calls (main thread) or make `open` treat that error as focus. Note from T-037 review round 2: the install smoke's window predicate (`scripts/ci/visible-windows.ps1`) ignores tool windows on purpose — an overlay or skip-taskbar window added here would slip past "a loaded start shows nothing"; revisit the script with the overlay.

## Acceptance

- [ ] Windows CI: integration test pastes a transcript (mock engine, injected WAV source) into a test window and the clipboard holds it, excluded from clipboard history
- [ ] Owner on Windows: hold Ctrl+Alt+Space in Notepad, speak, release → the text appears in Notepad; overlay visible, Notepad keeps focus
- [ ] A second launch does not start a second instance and opens the running one's settings
- [ ] Failure branch: start window replaced by another before delivery, or the target runs elevated → no Ctrl+V, text stays in the clipboard, notice "copied — paste manually"; microphone access denied → no recording state, notice "microphone unavailable" — verified by Windows CI tests on the fakes' calls and by the owner
- [ ] Test that fails without the change: `src-tauri/tests/delivery.rs (Windows CI)`
