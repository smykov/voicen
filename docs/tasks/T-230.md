## Context

Umbrella for CI and contour hardening (owner's grouping 2026-11-17, "Одна задача CI-закалки"). Guard paths: `checker: true`, `analysis.decides_on` (P-020); the byte-pinned fragments (`scripts/ci/contour-heads/`, `contour-upload.yml`, `release-*`) change in pairs (CLAUDE.md, ci.yml row).

- T-128 ci-hang#1: the windows job's shell-test steps carry no `timeout-minutes`, so a hanging test holds a run to GitHub's 360-minute default (run 43577968221 hung ~1.5 h in `call_launch.rs`); give the `cargo test` steps a bound (.github/workflows/ci.yml).
- T-199 r2#2: the wait inside the stage still rests on the launch prompt sentence; the kit loop has no "pushed, awaiting run" state — draft kit feedback (`/teamwright:feedback`) and watch `.teamwright/parallel/*.log` for a bare "CI unread" stage end (`scripts/tw-launch` `OUR_SENTENCE`).
- T-202 r2#7: the push step reads the runner user's home, which the session can write as the same OS user; set GIT_CONFIG_GLOBAL=/dev/null, GIT_CONFIG_NOSYSTEM=1, PYTHONNOUSERSITE=1, `git init --template=`, build the auth only after the fetches, list the rest in Not caught, add "separate OS user for the session" to the owner items (.github/workflows/teamwright-agent.yml:217-233; docs/decisions/ci-toolchain.md:165; scripts/ci/release-guard.sh R14-limits comment).
- T-202 r2#8: the push step's hooks come from BEFORE (the remote task/<ID> head a previous stage wrote), so a stage-N commit editing pre-push takes effect at stage N+1 unreviewed — archive the hooks from `${{ github.sha }}` or document the limit (teamwright-agent.yml:218-228; docs/process/gates.md "Pausing the contour").
- T-206 r2#2: the staging step holding JOB_TOKEN and OAUTH_VALUE runs grep/find/jq from an inherited PATH with no `BASH_ENV: ""` pin; pin BASH_ENV and a fixed PATH as the push step does, or state the limit (scripts/ci/contour-upload.yml; docs/decisions/ci-toolchain.md upload residual risk).

## Acceptance

- [ ] Every `cargo test` step of the windows job has `timeout-minutes`; a hang turns the run red within the bound.
- [ ] The contour push step runs with no user/system git config, no user site, an empty template, and builds its auth after the fetches; its hooks come from the dispatched main commit, or the limit is documented with an owner item.
- [ ] The upload staging step pins `BASH_ENV: ""` and a fixed PATH, or the limit is stated in the invariant.
- [ ] The T-199 kit gap is drafted for `/teamwright:feedback` (owner sends it).
- [ ] Failure branch: removing a timeout or an env pin → `make check` (release-guard / contour checks) fails, verified by the guard test.
- [ ] Test that fails without the change: `<guard test names>`
