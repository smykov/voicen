## Why FAIL

The analysis invariant says "The example never prints or logs transcript text, reference text or the key". That guarantee holds in the code today but no test protects it. Three one-line mutations of `crates/voicen-core/examples/wer.rs` print the transcript, the reference and the key. All three stay green, and each one did print its marker when run against a loopback mock with fake data. The Russian set is the owner's call data (`## Investigation`), so this is the harm class of owner decision #32 (NFR-04, FR-20).

`## Tests` records "no unit test by design", citing #185. R23 and T051 say the gate and CI do not run the example, which is the owner-run measurement. They do not exempt the invariant from test protection, and the validator's rule makes a surviving mutation of a critical guarantee a FAIL. The fix does not need the gate to run a measurement, see "What would close it". Nothing else in this round failed.
