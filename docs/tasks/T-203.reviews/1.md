The writer calls `consumer.audio` in `Writer::handle` before `apply`, and it is single-threaded. So every block that `barrier()` feeds afterwards is handled after all of 0..200 ms has been applied on both tracks, whichever order `Writer::drain` takes. Before `barrier()` the mono clock does not move after the first tick, so the next tick must come from a barrier block. Its levels come from a fully applied 0.5 / 0.0 span plus barrier blocks with the same amplitudes. `wait` uses `eventually(BUDGET, …)`, which is a hang bound and not a ceiling on a measured time, so F-021/I2 holds.
