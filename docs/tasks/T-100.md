## Context

FR-20 crash part, NFR-07. Core part of T-024, split by owner decision #134 (OQ-32, option A); accepted with it: frames through a `FrameSource` port (filled on Windows by `RtlCaptureStackBackTrace` in T-024) and no log line from the panic hook. T-024 wires it into the shell.

## Acceptance

- [ ] A forced panic (test hook) writes one crash file with only allowlisted fields; the payload never appears
- [ ] `Session::begin` gives one verdict per previous session (clean / crashed / ended by installer / ended abnormally) and at most one new record
- [ ] Failure branch: a crash file 20 days old survives retention; the 21st removes the oldest; a corrupt marker gives `EndedAbnormally` without panic — verified by core tests
- [ ] Test that fails without the change: `crates/voicen-core` tests `diag_session`, `diag_crash`
