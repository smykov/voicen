## Acceptance

- [ ] A call folder `<root>\YYYY-MM-DD_HHMMSS` is created from the local start time, with `-1`, `-2` on a clash, never an overwrite (T022, T023)
- [ ] `meta.json` is written from the start with `state: recording` in the data-model.md field order, with temp + rename on every state and device change, never in place (T022)
- [ ] The default title is "Call DD.MM HH:MM"; the speakers are `me` / `s1` with "Me" / "Other party" (EN) or "Я" / "Собеседник" (RU) (T022)
- [ ] Listing covers the current and every earlier root, newest first; `ready-to-transcribe` lists as Queued (T022)
- [ ] Failure branch: an unavailable root gives one `unavailable` line; a missing or unparsable `meta.json`, an unknown schema or a missing track file lists the folder as `damaged`, never hidden (T022)
- [ ] The `.voicen-write-probe` check runs at each start (T022)
- [ ] Test that fails without the change: the `call/storage.rs` tests

## Investigation

**Context gathering.** I used Serena (`get_symbols_overview` on call/events.rs, codec.rs, transcript.rs and clock.rs; `find_symbol CallId`), then grep and sed for the spec documents, settings/roots.rs, settings/service.rs, diag/format.rs and i18n.rs. Context7 was not needed: no new external API. The work uses std::fs only (`create_dir`, `rename`, `File::sync_all`) plus serde_json 1, which is already a dependency and keeps struct field order on serialize.

**Frame.** A feature task. Expected: core creates `<root>/YYYY-MM-DD_HHMMSS[-n]`, writes `meta.json` atomically from the start, and lists every root's calls with `damaged` and `unavailable` entries. Observed: no `call::storage` module exists, so none of this happens.

**Hypotheses, with evidence.**
1. *Nothing exists yet*: confirmed (ls of call/, grep for CallStore/DiskSpace/meta.json in crates/ and src-tauri/src).
2. *The same concern already has a path elsewhere*: confirmed, several times. Each one must be reused, not copied:
   - Write probe: `settings::roots::CallRoots::probe`. Its module doc says "there is no second probe", and T-125/T-126 call it at every Record start. Its `FsCallRoots` creates the default root, which a first call needs.
   - Current root: `settings::service::effective_root` (private). The store must resolve the root the same way save does. Recommendation: move it into roots.rs as `pub fn effective_root(&CallSettings, &Path)`.
   - Local time: `diag::format::LocalTime::of(at, seconds_east)` (pub(crate)). It feeds the folder name, `calls.title_default` (two-digit day/month/hour/minute) and `started_at`. transcript.rs fixtures use `2026-10-30T14:05:09+03:00`, with no millis; follow that form, so add a seconds-only writer beside `write_timestamp`, or format from `LocalTime` in storage.rs.
   - Atomic write: `settings::file::FsSettingsFile::write_tmp_and_rename` is tied to settings.json. The call side gets its own `write_meta` in storage.rs. T-138 (transcript.*) and T-141 (export) should reuse that tmp+sync+rename helper; expose it as `pub(crate) fn write_atomic(dir, name, bytes)` in storage.rs.
   - .opus writing: only through `OpusOgg::create` (T-116 invariant).
   - Types: `CallId`, `CallState` (hyphen serde, #195), `EngineRef`, `Speaker` (#196), `EndpointId` (invalid text never kept), `StopReason` and `FailReason` already exist.
3. *This class was fixed before*: not for calls. The closest precedent is settings (`docs/decisions/settings.md`): `create_new` reservation, so no backup is ever overwritten, and tmp+sync+rename. The same shape applies here: `fs::create_dir` (atomic, AlreadyExists → next suffix) instead of `create_dir_all`.
4. *`CallId`'s `Ord` gives newest-first*: refuted. It derives `Ord` on the String, so `…_101010-10` < `…_101010-2`. Listing must sort by a parsed key `(stamp, n)` descending, ties current root first. Do not change `CallId`'s `Ord` (events.rs, DONE).
5. *`StorageKind` can carry `StorageOp::Encode`*: refuted. There is no `encode` literal in `call_storage_failed kind=`, and #195 left the mapping to T-125. See D1.

**Shape for the developer** (indicative):
- `CallStore::new(roots: Arc<dyn CallRoots>, clock/offset)`.
- `create(&self, calls: &CallSettings, NewCall { started: SystemTime, seconds_east, mic: EndpointId, system: EndpointId, lang: UiLanguage, app_version }) -> Result<ActiveCallFiles, CreateError>`.
  - Order: probe → create_dir with suffix → `meta.json` (state recording, `results` both `pending`, `engines.transcription: null`, `pass_mode: null`) → `mic.opus`, `system.opus` via `OpusOgg::create`.
  - Any failure after create_dir removes what it created (best effort), so a refusal leaves nothing.
