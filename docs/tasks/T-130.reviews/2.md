## Verdict rationale

**The fix (3934c94b) is sound and keeps the invariant.**
- `restyle` reads `GWL_STYLE`, clears both `WS_CAPTION` bits, and writes the style only if it changed. It handles the error code the same way the ex-style write does.
- One `SetWindowPos(SWP_FRAMECHANGED | SWP_NOACTIVATE | SWP_NOMOVE | SWP_NOSIZE | SWP_NOZORDER)` applies both writes. The window is still hidden at that point, and the one raw `ShowWindow(SW_SHOWNOACTIVATE)` comes after it.
- No tao or tauri setter is added. The drag uses tao's `HTCAPTION` loop, which needs no caption bit; s5 and S7 are green.

**The page-load wait has no new deadlock or lost wake.**
- The `wake` condvar is waited on only by the indicator thread (`wait` and `wait_loaded`), so `notify_one` cannot wake the wrong waiter.
- `wait_timeout_while` releases the mailbox mutex while it waits. `on_page_load` runs on the main thread and takes the mutex only briefly.
- A `post` during the wait leaves `woken` set for the next main-loop wake. A `mark_loaded` that arrives after the timeout only causes a spurious wake, after which the loop rechecks.
- The generation is now read before `.build()` instead of after it. `.build()` does not touch the reducer, so the value is the same.

**Destroy, then `close`, is correct for the pinned tauri.**
- tauri 2.12.1 `Webview::close` (`src/webview/mod.rs:1643`) sends a queued `WebviewMessage::Close` and calls `on_webview_close`. That removes only the webview label and its JS listeners.
- The window's Rust `on_window_event` listener stays registered, so on Wry the real `Destroyed` still reaches the reducer, which waits for it before it rebuilds.
- If `close` fails after a successful `destroy`, the existing failure branch handles it. Either the label is gone and a synthetic `Destroyed` is posted, or the label is still there, the handle is kept, and the window's own `Destroyed` follows.
- The focus contract is unchanged. S3, S4, S5 and S7 run under variant N, and the evidence line shows `away []` and no focus losses.

**The test changes keep full strength.**
- No assertion was removed.
- S7 keeps its five conjuncts. Its `moved` check got stricter: it was `left != before.left`, it is now `|Δleft| >= |dx|/2`, as in s5. The assert message now prints the rectangles.
- The sleep (`GetDoubleClickTime()` + 200 ms) is an OS threshold, not a budget. The red run 44446192344 is the bite.
- `Shown::ok` now uses the visibility read inside `shown()`, while the window is alive. For every caller that asserts right after `shown()` this is the same check, and the old lazy read could only pass if the stop failed to destroy the window.
- Clearing `dev_url` makes the rig load the test page. It weakens nothing.
