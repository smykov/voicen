## Findings

1. **The task invariant is not protected by a test (test-writer).** "Only from a push to main or a `v*` tag whose earlier Windows steps all succeeded" depends only on the send step's `if:` at `.github/workflows/ci.yml:603`. Mutation M6 (no ref or event restriction, plus `always()`) leaves `make check` green. The wip runs only show the step as `skipped`; no check fails if that changes. The repo already pins `actions/cache/save` steps this way: `scripts/ci/ci-wip.sh` requires a `github.ref == 'refs/heads/main'` `&&` operand. A matching `make check` tripwire for any step that reads `secrets.TELEGRAM_BOT_TOKEN` would close the gap. It would require, with blanks removed, an `if:` with `github.event_name=='push'` and `(github.ref=='refs/heads/main'||startsWith(github.ref,'refs/tags/v'))` as `&&` operands, no status function (`always()`, `failure()`, `!cancelled()`, `success() ||`), and no `continue-on-error`. It needs a host fixture test that fails on M6.
