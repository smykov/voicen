## Context

Owner answers (decisions #59, #60): Q2 — the Silero model is downloaded in CI with a pinned SHA-256 (no binary in the repository); Q3 — real voice clips are public-domain recordings (CC0 or an explicit PD dedication), recorded in licenses/manual.json. Split from T-001 by decision #43. Decision #12 and spec 002 R-1 keep native/model code out of voicen-core, so `SileroDetector` lives in `crates/voicen-whisper` and implements core's `SpeechDetector` (T-041). The energy detector cannot reliably tell a long cough from speech; FR-12 on real audio is proven only by Silero on real clips (Windows CI) plus the owner.

Owner decisions 2026-10-12. #136 (OQ-34, option A): this task keeps the detector proven on real clips (the pin and `verify` in core, `SileroDetector` in `voicen-whisper`, the CI fetch and cache, the CC0/PD clips, `silero_clips.rs`, the notices entry) and ships nothing (`deploys: false`). T-102 ships it (the `--config` overlay bundle for `tauri build`, the `dictation.rs` wiring, the install smoke `detector=silero`). The CI fetch runs without a cache (orchestrator, 2026-10-20: the model is 885 KB, and a cache would need a new action line, a fragment and a key checker; the pinned SHA-256 of #60 still holds). #130 (OQ-29): the `voicen-whisper` crate is created by T-099, which this task depends on.

## Acceptance

- [ ] On Windows CI, the Silero detector classifies the real speech clips as speech and the real silence / cough / keyboard clips as not speech
- [ ] The model file's integrity is checked (pinned SHA-256) and its license is listed in the notices
- [ ] Failure branch: a missing or corrupt model makes the detector unavailable, and the gate falls back to the energy detector with the `vad_fallback` warning (no panic)
- [ ] Test that fails without the change: a Windows CI test in `crates/voicen-whisper/tests/`

## Investigation

Refreshed 2026-10-20 (at 99848d4, after T-099 DONE and decisions #130, #136). Tools: the Serena and Context7 tools were not available in this session; context comes from grep and file reads, from the whisper-rs 0.16.0 and whisper-rs-sys 0.15.0 (whisper.cpp 1.8.3) sources in `.teamwright/cache/core` (the core image's cargo registry, matching `Cargo.lock`), from the Hugging Face API (model metadata and the raw LFS pointer), from the whisper.cpp v1.8.3 README and `models/download-vad-model.sh` on GitHub, and from the Wikimedia Commons API (clip licences). The first analysis (2026-10-12) is superseded: its size verdict and options are decided by #136, and its crate premise by #130 / T-099.

**Frame.** Observed: every speech decision is the energy detector's (`dictation.rs` `run` builds `SpeechGate::new(Err(VadError::Unavailable), EnergyDetector::new())`, #62). Expected for this task (#136): a Silero detector behind core's `SpeechDetector`, proven on real speech and non-speech clips in Windows CI, with the model file pinned and verified. Out of scope (T-102): bundling, the `dictation.rs` wiring, the install smoke.

**What exists now.**
- The port and the fallback (T-041): `SpeechDetector`, `VadError`, `SpeechGate` with one `fallback_warning`; the pipeline's `Warning{vad_fallback}`; `DetectorTag::Silero` in the diag log.
- `crates/voicen-whisper` (T-099): `WhisperLoader` over whisper-rs, logging hooks installed before the first load, every failure an `Err`; `build.rs` gives every `tests/*.rs` exe the shell's CRT; `direct_dependencies_are_voicen_core_and_whisper_rs` pins the normal dependencies (so the Silero code must add none: the hash lives in core).
- The CI pattern (T-099): `examples/fetch_model.rs` fetches a catalog model through the one `Downloader` (streamed size + SHA-256, `.part` then rename); restore / fetch / save steps with a key of `hashFiles(catalog.rs)` and a byte-exact save fragment; `make check-whisper-model-key`; `scripts/ci/crt-imports.sh` over an explicit exe list.
- `sha2` in core (#50); a 1 s CC0 English speech clip (`crates/voicen-core/assets/connection-test-speech.s16le`, T-046).

**Hypotheses.**
1. *whisper-rs can carry the detector without a new dependency.* Confirmed: `WhisperVadContext::new(&str, params)`, `segments_from_samples(&mut self, params, &[f32])`; `Send + Sync` impls, so a `Mutex` makes it a `&self` detector. Segment times are centiseconds (`samples_to_cs`).
2. *A bad model file fails cleanly in whisper.cpp.* Refuted (unchanged from the first analysis, line numbers re-checked): no try/catch in `whisper_vad_init_with_params`; a file-supplied `str_len` sizes a `std::vector`; explicit `throw std::runtime_error`; short reads are not detected. A C++ exception through `extern "C"` aborts the process. whisper-rs also panics on a NUL in the path. Hence invariant (1): verify against the pin first.
3. *The Silero fetch can reuse `fetch_model` as is.* Partly refuted: the example, `Downloader` and `ModelStore` are keyed by the catalog's `ModelId`; Silero is not a user-selectable model, and adding it to the catalog would widen its shape tests and the UI's model list. A separate fetch in the example cannot build its own HTTP client (`engine::http` is `pub(crate)`, and `clippy.toml` denies reqwest clients outside it, T-089). So the transfer in `local_models::download` is factored to take a pin, and `vad::silero_model::fetch` and `Downloader` both use it (invariant 4).
4. *The model needs a CI cache like the tiny model.* Not needed: 885 KB per run. A cache would add an action line, a save fragment in `scripts/ci/cache-steps/` and a key check (guard-model class, P-020 checker task) for no proof gain. An HF outage turns the job red, never a skip, as a tiny-model cache miss already can.
5. *The same concern is handled on a second path.* Gate builders: `dictation.rs` (production, T-102), the core tests and `pipeline.rs` unit tests, the shell tests (`tray.rs`, `hotkey.rs`). All choose their detectors on purpose; this task changes none. Pinned downloads: one transfer (invariant 4).
6. *This class was fixed before.* No: `docs/failures.md` has no VAD or `transcription-pipeline` entry; `recurrence_of: []` holds. Classes this task touches: `ci-premise-unchecked-before-main` (every native proof is CI-only: P-016 run on `wip/T-043` before review); `ci-toolchain` (F-001: `silero_clips-*.exe` must be added to the crt-imports step, `build.rs` already gives it the CRT); `guard-model` only if a cache is added.

**Model.** `ggml-org/whisper-vad` (MIT) at commit `9ffd54a1e1ee413ddf265af9913beaf518d1639b` (still the repository head on 2026-10-20). Both files are 885 098 bytes:
- `ggml-silero-v6.2.0.bin`, sha256 `2aa269b785eeb53a82983a20501ddf7c1d9c48e33ab63a41391ac6c9f7fb6987`;
- `ggml-silero-v5.1.2.bin`, sha256 `29940d98d42b91fbd05ce489f3ecf7c72f0a42f027e4875919a28fb4c04ea2cf`.

Source: HF tree API (LFS oid and size) and the raw LFS pointer of v5.1.2, 2026-10-20; the CI fetch's hash check is the cross-check. Correction to the first analysis: the whisper.cpp v1.8.3 README documents `silero-v6.2.0` (its download script lists both). Proposed: v6.2.0; v5.1.2 only if v6.2.0 fails the clip test, with the reason recorded.

**Clips (decision #59).** Licences read from the Wikimedia Commons API (`extmetadata` and the file page's licence template) on 2026-10-20. Each becomes a short excerpt converted to 16 kHz mono s16le under `crates/voicen-whisper/tests/clips/`, with source URL, title, author/reader and licence in `licenses/manual.json`.
- Speech: `File:The Practice of the Presence of God - First Letter - Librivox.ogg` (LibriVox public domain, reader Kirsten Ferreri; a 3-5 s excerpt); `File:LL-Q7737 (rus)-Svetlov Artem-Аэрофлот.wav` (CC0, Lingua Libre, about 1.3 s, Russian); the existing `connection-test-speech.s16le` (CC0).
- Cough: `File:Woman coughing three times.wav` (CC0, Freesound 151212 by Ashe Kirk / OwlStorm, 1.6 s); `File:Man coughing.ogg` (PD-author stilgar, pdsounds 625, 4.8 s).
- Keyboard: `File:Typing - Model M 1986.ogg` (CC0, own work of Raymangold22, 12 s); `File:Laptop keyboard.ogg` (PD-author russiandoll, pdsounds 554).
- Room noise: `File:Alien machine room air ducts.ogg` (PD-author stephan, pdsounds 320, 12.5 s). Avoid ambiences with voices (for example `Ambient classroom mono.ogg`).
- Silence: digital zeros generated in the test (no file).
- Rejected (CC-BY / CC-BY-SA, not allowed by #59): `En-us-cough.ogg`, `De-husten.ogg`, `Husten zwei mal.ogg`, `Typing on Keychron V1 Ultra ...wav`, `Open-space office ambiance.ogg`.

Conversion: the `.wav` sources decode with Python's stdlib `wave`; the `.ogg` ones need a Vorbis decoder (no ffmpeg or sox on the host or in the images). That is a one-time setup step (for example ffmpeg in a disposable container), not an owner decision; if the owner declines that download, use only the WAV sources (speech from Lingua Libre CC0 sentences, the CC0 cough WAV, an excerpt of the CC0 `File:399603 dustin-davis typing.wav`, 272 MB) and say so in the task.

**Decision rule.** `segments_from_samples` with fixed params (start from the whisper.cpp defaults: threshold 0.5, min speech 250 ms, min silence 100 ms, pad 30 ms); speech iff the summed segment length is at least a minimum. The constants are pinned red-then-green by the clips as a set. If no fixed rule rejects both cough clips without losing a speech clip, that is an owner finding about FR-12 on real audio; it must not be tuned clip by clip.

**Notes for T-102 (not this task).** `load` refusing a CPU without AVX2 (#142 baseline) keeps a non-AVX2 machine on the energy detector instead of an illegal instruction once the shell loads Silero at start; T-017 decides whether whisper.cpp may be linked into `voicen.exe` at all on such CPUs. The `verify` then native-open sequence has a time-of-check gap on a file the user can replace; accepted for a per-user install directory.

**Recommended exit**: n/a (feature task, not rca).
