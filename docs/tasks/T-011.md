## Context

FR-23; delivery slot assigned at recording stop (spec 001 FR-029). Built on T-001's `Pipeline::run_job` private `process`/`release` halves: put the queue between them. Note from T-001 review rounds 1–2: `keep_pending` holds the slot lock across store and swap, but that is only a safeguard — `release` still runs on one delivery thread, because the clipboard write → modifier wait → Ctrl+V sequence in `deliver` interleaves across concurrent jobs (research R-10); `process` may run concurrently.
