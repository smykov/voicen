Cause of each failure, read from the Playwright traces:

The page snapshot was SvelteKit's `500` / `Internal Error`, so the page code never ran. The chunks named were `chunks/BecTHFt6.js`, `chunks/DKUjMQVT.js`, `nodes/3.y4gabOU_.js` and, in one case, `nodes/0.CIexCk49.js`. `docker events` showed bridge and network connect/disconnect events from other projects inside the run windows.
- The other two failures were renderer crashes at `page.goto` (`Page crashed`) and left no trace.
- No run failed on an assertion about page behaviour.

The gate's own Playwright step hit the same `ERR_NETWORK_CHANGED` boot failure once (`:589`), and the re-run was clean (see validation/1.md). Finding for the orchestrator: on this shared host, Playwright boots are not reliable while other containers start and stop. This is a finding about the environment, not about T-039; CI at the same commit passed 54/54 on the first attempt.
