**3. listen_any audit (F-018, T-096 r1#1).** Mechanism checked in the product: `settings_window::open` emits `settings://focus` synchronously on the opener thread, and the opener sends the receipt only after `open` returns (`src-tauri/src/settings_window.rs` opener loop, `done.send(result)`). Safe: the first launch builds the window (a build emits no focus), its receipt is waited (`ran(..)`), and any emit is synchronous before that receipt.
