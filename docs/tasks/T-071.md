## Context

The owner asked on 2026-10-07 for a tray menu item to look at the log ("В трее добавить пункт меню посмотреть лог"). While diagnosing T-006 they had to find `%LOCALAPPDATA%\Voicen\logs\voicen.log` by hand. FR-20 defines the log: local, rotating, with no transcript, audio or keys, so opening it shows nothing secret. The tray menu lives in `src-tauri/src/tray.rs`.

## Acceptance

- [ ] The tray menu has an item "Open log folder" ("Открыть папку логов"), both strings in the en/ru catalog (FR-15). Clicking it opens `%LOCALAPPDATA%\Voicen\logs` in Explorer, with the newest `voicen.log` selected or simply the folder (the analysis decides).
- [ ] Failure branch: the folder is missing or cannot be opened → it is created if missing, and if Explorer cannot be started a warning line is written to the log (no path or user name beyond what FR-20 already logs) and the app keeps running. Verified by a shell test.
- [ ] Test that fails without the change: named in `## Tests`.
