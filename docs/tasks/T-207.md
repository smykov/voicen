## Context

Decision #271 (OQ-85, option c). T-062 moved the WebView2 user data of every Voicen window to `%LOCALAPPDATA%\Voicen\webview`. A machine upgraded from a build before T-062 keeps `%LOCALAPPDATA%\dev.voicen.app` (a rebuildable WebView2 profile; settings live in `settings.json`), and neither the app nor the uninstaller removes it (`docs/decisions/installer.md` › WebView2 data). The owner chose: the installer (on upgrade) or the uninstaller removes that folder; no app code. The NSIS hooks live in `src-tauri/windows/installer-hooks.nsh`.

## Acceptance

- [ ] Windows CI: a planted `%LOCALAPPDATA%\dev.voicen.app` (with a file inside) is gone after the installer runs over it (upgrade path)
- [ ] Windows CI: a planted `%LOCALAPPDATA%\dev.voicen.app` is gone after uninstall, also when kept calls stay (default uninstall without `/PURGECALLS`)
- [ ] Failure branch: nothing outside `%LOCALAPPDATA%\dev.voicen.app` is removed — a sibling folder (e.g. `%LOCALAPPDATA%\dev.voicen.app.keep`) planted next to it survives both paths
- [ ] Test that fails without the change: the Windows CI step named by the analysis
- [ ] `docs/decisions/installer.md` › WebView2 data updated (OQ-85 → #271)
