## Acceptance

- [ ] T-116 r1#1 Low ssot-violation: the codec defines its own `RATE = 16_000` and a literal `16` in `next_window`, repeating `crate::audio::SAMPLE_RATE`; derive both from it (crates/voicen-core/src/call/codec.rs:41, next_window vs crates/voicen-core/src/audio/mod.rs:16)
- [ ] T-116 r1#2 Low correctness: a bit flip in a page's segment count or lacing table near EOF makes the bad page run past EOF, so the reader reports `Truncated` instead of `Damaged` (same recoverable audio); state it in the contract or rescan from the bad page's start + 1 before storage relies on the difference (crates/voicen-core/src/call/codec.rs `Pages::after_bad_page`)
- [ ] T-116 r1#3 Low toothless-test: no test pins complexity 9 or FEC off, and Voip is pinned only together with VBR and DTX (W15) (crates/voicen-core/src/call/codec.rs tests `encoder_uses_the_r5_settings`)
- [ ] T-116 r2#1 Low toothless-test: a swallowed write error in `encode_frame` (`let _ = self.write(…)`) is killed only by an ogg 0.9.2 internal panic (`writing.rs:161`), not by an assertion; add a `first_failing_push` case that fails one write only and asserts `push` returns `StorageError{op: Write}` (crates/voicen-core/src/call/codec.rs tests)
- [ ] T-116 r3#1 Low toothless-test: `consecutive_bad_pages_up_to_the_end_of_the_file_end_recoverable_data` cannot tell a CRC-failure run from other read errors by its result (both `Truncated`); it relies on the sibling test proving `corrupt_run` yields `HashMismatch` — note it at `corrupt_run` or assert it (crates/voicen-core/src/call/codec.rs tests)
- [ ] T-116 r4#1 Low toothless-test: OpusHead tests cover only rejected values; no accept case for a valid head with version 2…15 or 2 channels, so narrowing mutants (`*version == 1`, `*channels == 1`) survive; add accept cases if the reader stays RFC-tolerant (crates/voicen-core/src/call/codec.rs:311, tests :1477)
- [ ] Failure branch: one failed write in `encode_frame` makes `push` return `StorageError{op: Write}`, asserted by the test, not caught by an ogg internal panic
