## Acceptance

- [ ] Call mode is off at construction (T024, T025)
- [ ] Tray, hotkey and switch enter `toggle_record(on, Source)` under one lock; a repeated on gives one session, one capture per track and one folder; off then on gives a second folder (T024)
- [ ] Failure branch: a track failing to open (`no_device`, `access_denied`, `busy`, `other`) or a missing or unwritable root refuses the start with `call_refused part= reason=`, no track left open and no folder left; system opens first, then mic, then root (no devices → `part=system reason=no_device`); an unwritable root also asks to open the Calls tab (T024)
- [ ] A missing selected mic with a default input present starts on the default input with `mic_changed` (T024)
- [ ] Subtitles-only writes nothing to disk (FR-019) (T024)
- [ ] `stop(StopReason)` closes both files readable, sets `ready-to-transcribe`, emits `call_saved_transcribing` and logs `call_stopped` with byte counts (T024)
- [ ] `IndicatorState` / `IndicatorTick` change inside the lock; the reminder and headphones hint show for 10 s at each start and not at all when `reminder` is off (T024)
- [ ] `provider_notice{host}` is emitted once for the first session on a new non-loopback host (`warned_hosts`) (T024)
- [ ] Esc and dictation never change the call (T024)
- [ ] `e2e/fixtures/call-indicator-wire.json` is pinned by a core test (T024, T025)
- [ ] Test that fails without the change: the `call/session.rs` tests
