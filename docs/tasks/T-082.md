## Context

Process review 2026-10-09 (`tw-context.py --json`): 7 of 90 code reads over 13 sessions went through Serena, every one of them from the main session. The subagent roles read with built-in tools only: developer-core 34, problem-investigator 20, task-validator 16, test-writer-core 8. Svelte (16 files) is not indexed, because the ui area runs in Docker and the host has no Svelte language server.

## Acceptance

- [ ] Each role file in `.claude/agents/` that reads code names the context tool in its tools and first step, and a subagent session can call it (shown by one run whose journal records a Serena call from a subagent)
- [ ] Svelte is indexed by Serena on the host, or `docs/decisions/` records why not and what the roles use instead
- [ ] Failure branch: when the context tool is unavailable in a session, the role instruction says to fall back to built-in reads, not to stop
