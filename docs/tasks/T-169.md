## Investigation

**Frame.** Expected: one rule says "a model is set when it is non-empty after trim". Both engine arms apply it the same way. The stored base URL is kept as typed, minus trim and one trailing `/` (decision #96, decisions/settings.md T-072 section). Observed: the API arm of `engine::engine_for` sends `api.model` raw. The predicate is written out by hand in four places. No core settings test pins that an endpoint suffix survives save. Reproduces through a hand-edited `settings.json`, because `SettingsService::load_or_init` stores the parsed file without `normalize`. Save and Test connection do normalize.

**Hypotheses.**
1. The API arm has no trim (confirmed: `engine/mod.rs:89`, `openai.rs:215`).
2. Second path: the same concern is handled elsewhere. Confirmed, there are four copies: `engine_for` LocalServer arm, `service::normalize`, `settings::validate::validate` (API model required), and `post_process::settings::validate`. A fifth reader, `call::final_pass::api_engine` with `EngineRef`, takes `api.model` raw by contract (`specs/007-call-mode-record/contracts/core-call.md:62`, "A blank model is not checked"). It is left out of this task.
3. Load normalizes, so the bug is unreachable. Refuted: `load_or_init` → `parse_file` → `LoadOutcome::Loaded(settings)` has no `normalize` call. `normalize` is called only in `save` and `connection_test`.
4. This class was fixed before. Yes, for the local arm only: T-018 added the trim and `tests/local_server.rs::whitespace_only_model_omits_model_part`, and did not extend it to the API arm. No `docs/failures.md` entry covers model trimming or URL suffix stripping (grep for trim/blank/whitespace: none). The nearest principle is P-010 (one source of truth). This is not a recurrence that needs an rca.
5. The URL half: `normalize_base_url` might strip the suffix today. Refuted (`url.rs:31`: trim plus one `/`). The gap is only that no settings-level test pins it.

**Product decision.** Settled. Decision #96 and decisions/settings.md ("Don't: strip `/audio/transcriptions` from the stored value on save") fix how the URL is stored. The acceptance line fixes the blank-API-model result: the same as the local-server arm, so the model part is omitted. Option B (`EngineNotConfigured`) is listed only as an alternative. No `blocked_on`.

**Size.** Not large: one crate (`voicen-core`), one seam (the model-name helper) plus tests. T-120 (dependency) is DONE.
