## Context

FR-15 (v4: user-written text is shown as is). Catalog `i18n/en.json`, `i18n/ru.json` at the repository root, read by Rust (`include_str!`) and by the UI (alias `$i18n`). Every feature adds its keys here; a test fails when a key lacks a non-empty text in either language. Needed by toasts (T-007) and the settings window (T-004). Owns all of `voicen_core::i18n` — catalog embed, `UiLanguage`, `text()`, `MESSAGE_IDS`, `resolve_ui_language(os_tag)` (spec 004 T010, T011, T046, T048) — which T-003's `defaults()` consumes (decision #21).

## Acceptance

- [ ] `voicen_core::i18n::text(lang, id, args)` and the UI `t(id, args)` render the same text for the same id
- [ ] OS language Russian → `ru`; any other → `en`
- [ ] Failure branch: a key present in `en.json` but missing or empty in `ru.json` makes the catalog test fail with the key name; an unknown OS language falls back to English — verified by core and vitest tests
- [ ] Test that fails without the change: `crates/voicen-core i18n completeness test; src/lib/i18n.test.ts`
