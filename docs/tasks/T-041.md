## Context

Split from T-001 by decision #43. FR-12: silence, a cough or keyboard noise must not reach the engine. Core gets the `SpeechDetector` port and an `EnergyDetector` (the fallback on Linux and when Silero is unavailable); `SileroDetector` lives in `crates/voicen-whisper` (decision #12, spec 002 R-1) — that is T-043. From the T-001 Investigation: the energy rule as R-5 words it counts keyboard clicks as speech, so the gate must require a minimum run (~90 ms) of loud frames; an energy detector cannot reliably tell a long cough from speech — real-audio FR-12 is proven only by Silero on real clips plus the owner. Fixtures are generated in test code with a fixed-seed generator (`rand` not consented): harmonic "speech", a −60 dBFS noise floor, a 150 ms noise burst for the cough, 10–20 ms clicks for the keyboard. Depends on T-040 for `AudioBuffer`.

## Acceptance

- [ ] The 3 s synthetic speech fixture is speech; silence, the 1 s cough burst and keyboard clicks are not (energy detector with the minimum run)
- [ ] The gate uses the given detector and falls back to the energy detector when it is unavailable, emitting a `vad_fallback` warning once
- [ ] Failure branch: a detector error never panics and never lets audio through as speech by accident — the gate falls back (unit test with a failing fake detector)
- [ ] Test that fails without the change: unit tests in `crates/voicen-core/src/vad/`
