## Investigation

Tools: Serena and Context7 were not connected; context came from grep/file reads, whisper-rs/whisper-rs-sys sources downloaded from crates.io, and a scratch probe crate built in `voicen-rust:1.99` (outside the repo).

**What exists vs what is left.** Done and reused: `Engine`/`TranscribeRequest` and `EngineFactory` (pipeline, retryable failure keeps the pending recording), `DictationSession` with its `engine_factory` slot (T-051), `dictation_gate` (blocks only `EngineKind::None`, so no-model is a job-time failure), `Timeouts.builtin` per job (T-073, #99), `ModelStore::path_if_downloaded` and the pinned catalog (T-016), the `ModelRelease` port (T-019), diag `EngineTag` "builtin", `ShellRequests::open_settings`, licence entries for whisper.cpp/ggml and the Whisper weights (`licenses/manual.json`), the CC0 speech clip `crates/voicen-core/assets/connection-test-speech.s16le` (usable as the WAV fixture, P-010/#59). Missing: everything in the `root_cause` list. Also missing and needed: an injected monotonic time source for the residency (core `Clock` is wall-clock only; `scripts/ci/core-test-clocks.sh` forbids `Instant::now` in core tests), i16→f32 conversion, `JobFinished` warmth/load_ms fields (spec FR-015), `MODEL_IDLE_UNLOAD`, a prewarm hook in `DictationSession`.

**Dependencies and consent.** whisper-rs is in the owner's list (decision #9); whisper-rs 0.16.0 and whisper-rs-sys 0.15.0 are Unlicense (accepted), whisper.cpp 1.8.3 MIT (already in manual.json). New build-only crates (bindgen 0.72, clang-sys, cexpr, nom, itertools, prettyplease, glob) are MIT/Apache/BSD and cargo-about ignores build deps. CI download of tiny through the app's downloader is decision #49 (R-10; #60 precedent). No new consent needed. MSRV 1.88 ≤ 1.99.

**Linux gate feasibility.** `make check-shell-windows` cross-checks `voicen` for `x86_64-pc-windows-gnu`. Once `voicen` depends on `voicen-whisper`, whisper-rs-sys's build script runs bindgen (works: clang 14 in the image) then cmake, which fails: the image has `gcc-mingw-w64-x86-64-win32` but no mingw g++ (probe log reproduced). Options: (a) set `DOCS_RS=1` for the gate's check only — whisper-rs-sys's build.rs then skips the native build and type-checking still works (probe: passes); native build and tests only in Windows CI (#12). (b) add `g++-mingw-w64-x86-64-posix` and really cross-build (image change, slower, posix thread model needed, still not the MSVC build that ships). (c) build voicen-whisper natively on Linux for tests (extra minutes per gate, proves nothing about MSVC). Recommend (a), recorded in `docs/decisions/ci-toolchain.md`; check-core is unaffected while voicen-whisper stays out of `-p voicen-core`.

**Windows build risks (ci-toolchain class, F-001/F-002/F-011).** (1) `GGML_NATIVE` defaults ON (ggml/CMakeLists.txt:102-106): the runner's CPU features are baked in, so the installer can crash with illegal instruction on user CPUs. Pin `GGML_NATIVE=OFF` (whisper-rs-sys passes `GGML_*` env to cmake; `.cargo/config.toml [env]`); then ggml defaults to an AVX2/BMI2/FMA baseline — owner question 1. (2) tauri-build links the static VC runtime (`/NODEFAULTLIB:msvcrt`, libcmt); cmake-rs picks `/MD` unless `crt-static` is on → likely LNK2038/unresolved CRT symbols in the shell link. Prove on the wip CI run (P-016) before review; fix by `CMAKE_MSVC_RUNTIME_LIBRARY`/static_crt alignment, not by disabling the static runtime. (3) debug builds use RelWithDebInfo + `WHISPER_DEBUG`; test time with tiny is acceptable. (4) `FullParams::set_print_special/progress/realtime/timestamps(false)` and no `install_logging_hooks` routing to the app log — whisper.cpp prints segment text otherwise (FR-20). (5) `set_abort_callback_safe` gives cooperative abort for the 120 s limit; the model stays usable afterwards; a ggml abort() remains the accepted risk of #11.

**Size verdict: split.** The task spans four seams (native crate + build, core residency/engine/failure reasons, shell wiring, CI cache/guards) and at least two CI-only proofs; one task would mean several red wip runs with mixed causes. Proposed (option A, recommended):

Orchestrator: the "settings link" on the no-model notice needs T-007's toast actions (T-007 is TODO and not a dependency); T-017 can supply only the reason → `OpenSettings(engine)` mapping.
