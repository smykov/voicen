## Investigation

**Frame.** Item 1 (T-099 r1#4) is a real defect, but only at the deadline edge: a transcription whose last stop callback answered "go on" but whose `whisper_full` returns after the limit is reported `Timeout`, and its finished transcript is dropped. Items 2 and 3 are test gaps, not defects. Nothing was reproduced locally (the crate is built and tested only in Windows CI); the mechanism is read from the code and the pinned whisper.cpp source.

**Hypotheses.**
1. *The post-`full` read decides* (confirmed). `WhisperModel::transcribe` calls `abort.requested()` after `self.state.full(..)`. `Abort::requested` reads the clock and latches `fired` on its first true answer. A run that is finished but returns past the limit therefore gets `Err(LocalEngineFailed)` and `fired = true`.
2. *Second path* (confirmed, and it matters). `ModelGuard::transcribe_within` decides `Timeout` on `abort.fired()`, not on the model's result. So the fix cannot stop at "return `Ok` despite the late read": any read after the work latches `fired`, and the residency still reports `Timeout`. The model must not read the clock outside a stop point at all.
3. *whisper.cpp can return `Ok` after an honoured stop* (confirmed). The `encoder_begin_callback` answering false only `break`s the window loop, so `whisper_full_with_state` returns 0 with partial segments. The `abort_callback` returns -6/-8/-9. So deciding on `ran` alone would make a pre-requested abort `Ok("")`. The decision needs a latch of "a callback said stop".
4. *A callback can answer true without stopping the run* (refuted for whisper.cpp 1.8.3). Every true answer ends the run. The `ggml_backend_sched` graph path installs no per-node abort callback; abort is checked after each encode and decode graph and before each encode.
5. *Fixed before* (no). T-109 I3 changed the abort *test* to count segments. `docs/decisions/builtin-engine.md` already notes that the post-`full` read made the old "clock reads >= 1" check always true. Nobody changed the read itself.

**Evidence (whisper.cpp source, `whisper-rs-sys-0.15.0/whisper.cpp/src/whisper.cpp`, read from the cargo cache of the T-130 worktree; Context7 not used for it).**
- `whisper_full_with_state`: when the mel has fewer than `delta_min = 10` frames, it logs "input is too short" and returns 0 before any callback runs. 800 samples give `n_len_org = 4`.
- In the window loop, the check `if (seek + delta_min >= seek_end) break;` comes before `encoder_begin_callback`. So the last read of a complete run is the `abort_callback` at the end of `whisper_decode_internal`.
- whisper-rs 0.16.0: `WhisperVadContextParams::default()` sets `n_threads: 4`, has no getter, and derives `Debug`. Its inner `whisper_vad_context_params` is `#[derive(Debug)]`. `whisper.h` exposes no VAD thread getter.

**Root cause.** The model decides "aborted" from the clock at return time instead of from what its stop callbacks answered, and the residency's `fired` latch turns that late read into `Timeout`.

**Why the edge cannot be hit by a scripted clock on a normal clip.** A test that counts clock reads cannot tell the post-`full` read from the last callback read. If expiry is set at "the last read", the fixed code is also red, correctly: the last decode's `abort_callback` really stops the run with -8. A test that calibrates itself from a baseline shifts by the same one read. So the deterministic red test uses audio that whisper finishes with zero stop points: under 100 ms, with a fixed language. On that audio the only possible read is the faulty one.

**Test-gap items.**
- The quiet child loads only through `new()`. The `install_logging_hooks()` call in `load_whisper` (needed for `Default`) is never exercised as a process's first load.
- No transcript has two segments from separate 30 s windows.
- No non-English fixed language is tested.
- `print_special` is unobserved. whisper.cpp adds tokens >= eot (`[_BEG_]`, `[_TT_n]`) to segment text when it is on.
- VAD: `VAD_THREADS` reaches only `params.set_n_threads`, which nothing reads. The `Debug` text of the params is the only non-timing reader available. It pins the value handed to whisper.cpp, not the runtime cost; that stays timing-only and printed (F-013).
