## Context

Split from T-053 (its analysis, 2026-10-05: cut along the two seams). T-053 keeps the core overlay payload (Rust-rendered text, `e2e/fixtures/overlay-wire.json`) and the UI (`/overlay` route, store, Playwright). This task takes the shell half, which only Windows CI can prove: `src-tauri/src/overlay.rs` — the overlay part of the shell `Indicator` (`set_overlay` records the newest state and wakes one overlay thread; it never blocks under the session lock and never touches a window), the one overlay thread that builds / emits / destroys the window (never inline on the main thread; a new window only after the old one's Destroyed — tauri frees the label only then), a window that becomes visible only through a non-activating call after all styles are set and gets no tao setter while visible (tao re-shows with SW_SHOW), the `overlay_ready` command; the platform-free window-lifecycle reducer in `crates/voicen-core/src/overlay.rs` (state change and Destroyed in; Build, Emit, Destroy out) proven on Linux; `capabilities/overlay.json` (label overlay: listen / unlisten only); `scripts/ci/visible-windows.ps1` counts tool windows (F-003: decide on raw window facts; exclude only tao's event-target window by class). Evidence and invariant: T-053 analysis (tauri-runtime-wry 2.12.1 lib.rs:263-336, tauri app.rs:2709-2715, tao 0.37.1 window_state.rs:293-295, :455-467). T-006's wiring passes the one shell `Indicator` (tray part T-052, overlay part here; a no-op part until each lands). Position and look: OQ-10 (non-blocking; defaults apply). T-056's Linux windows-gnu type check lands first.
