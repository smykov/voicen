- **Wrapper branches and recursion guard.** On the host, a missing image exits 3 before any `run` or `pull`. A runner other than docker, or no image, exits 3 without falling back to the host. The re-entry passes `VOICEN_E2E_REENTERED=1`, and the image branch refuses when the marker file is missing, so a non-Playwright image cannot recurse. I checked by reading that today's `runner: host` config would have stopped with "names no image".
- **E1 sweep.** `run-<pidns>-<pid>-XXXXXX` with the pidns inode from `readlink /proc/self/ns/pid`. A dir of the same namespace is judged by whether its pid is alive. A dir of another namespace, or a legacy name, is judged by age over 24 h. That fits the test-writer's contract (any limit up to 48 h). The mkdtemp suffix has no `-`, so the regex cannot misparse it. The only other reader of the dir is global teardown, which goes by owner pid in the same process and is unaffected. If a dead namespace's inode is reused, a dead dir can be swept or kept, but never a live dir, because two live namespaces cannot share an inode.
