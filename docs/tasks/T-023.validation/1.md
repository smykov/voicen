## Finding (for test-writer)

Guarantee "About never shows a value from an earlier opening" (analysis invariant; settings-ui.md § A "each such opening clears the previous result … while pending nothing is shown") is not protected by a test. The fix needs no product code: add a way to hold `get_build_info` in `e2e/support/tauriMock.ts` (like the existing holds for other commands), and an `e2e/about.spec.ts` case. The case opens with an OK answer, closes, holds the next answer, and reopens. While the call is held, the dialog must contain no version line and no alert. After release, it must show the new line. That case must go red on M2. It would also cover the "Not covered: pending" gap in `## Tests`. Optionally it can cover the dropped late answer (`current === opening`) by releasing a held answer after a reopen.
