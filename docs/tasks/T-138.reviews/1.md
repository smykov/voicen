- **One engine, built once.** `api_engine` uses `check_base_url` and makes one `creds.read`. It never calls `engine_for`.
- **Contiguous windows.** Window starts are the sum of the floored lengths (`pos_ms`), and the ask is `TIMED_MAX_MS - carry_ms()`.
- **Bounded memory.** `refill` decodes only while a lane's queue is empty.
- **At most 3 in flight, in order.** The cap is `MAX_IN_FLIGHT`, and the next chunk is picked by call time with mic first on a tie.
- **VAD fallback.** It is sticky per track, gives energy spans and never empty spans, and is logged once.
- **Time-less switch.** It is strict in dispatch order: later chunks that are in flight, answered or queued are re-cut and sent `Plain`. Timed audio is kept only while an earlier timed request is still in flight (`release_audio`).
- **First failure.** A track's first failure clears its queue and drops its later answers. A `requeue` into a dead lane is a no-op.
- **Writes.** The order is validate → md → json → meta, each through `write_atomic`. Every `Err` is logged and ends as `failed: storage`.
