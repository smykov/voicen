## Context

T-162's investigation found that `scripts/hooks/test-guard.sh` strips `nice`, `timeout`, `env` and similar prefixes but not `systemd-run` and its options. Heavy runs prefixed with `systemd-run --scope -q --slice=agent-tests.slice --` (the host-load rule) therefore bypass the test guard and the tw-gate cache. The hook is kit-owned, so the change also goes upstream as kit feedback. It is a word-model guard: `checker: true`, and `analysis.decides_on` must name the token on the stripped prefix list.

## Acceptance

- [ ] `systemd-run --scope -q --slice=agent-tests.slice -- <runner>` is judged like `<runner>` alone: a cached gate or test run goes through tw-gate / tw-test as without the prefix
- [ ] `analysis.decides_on` names the `systemd-run` token and the options it strips
- [ ] Failure branch: a direct test runner behind the prefix (e.g. `systemd-run --scope -q --slice=agent-tests.slice -- cargo test`) is still refused
