# The helper-window manifest (T-065, rca smoke-window-predicate, F-008; docs/decisions/overlay.md §5).
# The one source for "which framework windows of voicen.exe are helpers": read by the install
# smoke's predicate and census (scripts/ci/visible-windows.ps1 Get-ShownWindows, Get-HelperDrift)
# and by the shell tests (src-tauri/tests/helper_windows/mod.rs is_helper). Checked on the Linux
# host by scripts/ci/helper-windows.sh (make check): every crate@version (with its resolved
# features) of the shell's Windows dependency graph whose source mentions CreateWindowEx has
# exactly one entry here, every entry is such a crate, and no visible-helper class is a product
# window class of the graph (a window_classname("<class>") literal, today tauri-runtime-wry's
# "Tauri Window"; F-003). Checked on Windows CI by the census: every visible-helper class exists in the
# real voicen.exe, and no visible, unowned, top-level window with the four helper ex-style bits
# (LAYERED, TRANSPARENT, NOACTIVATE, TOOLWINDOW) has a class not listed as visible-helper.
#
# Format: <key> | <verdict> | <class or -> | <source citation>
# (no `|` inside a field). <key> is <crate>@<version> for a binding entry, whatever its features;
# for any other verdict it is <crate>@<version> when the crate's resolved feature set (cargo
# metadata resolve.nodes[].features for x86_64-pc-windows-msvc) is empty, else
# <crate>@<version>[<f1>,<f2>,...] with the features sorted bytewise, comma separated, no spaces:
# a feature can change the windows a crate creates (tauri-plugin-single-instance's `semver` adds a
# version suffix to its class), so a feature change is drift at its commit. Verdicts:
#   visible-helper  creates a top-level, unowned helper window with the four bits and makes it
#                   WS_VISIBLE: excluded by the smoke only by this class AND the four bits; never
#                   a product window class (make check refuses it);
#   hidden-helper   creates a helper window of that shape that is never WS_VISIBLE: not excluded
#                   (if it turns up visible it counts and the census reports it);
#   child           creates only child windows (WS_CHILD of a product window): never top-level;
#   binding         declares the Win32 function only (a bindings crate), creates no window.
# {identifier} in a class is src-tauri/tauri.conf.json `identifier`.
# A tripped check means: read the cited source of the new version or feature set, then change the
# entry (or add one) in the same commit as the dependency change. Citations are paths inside the
# crate.
